## 先看结论与边界

在同位置、同参数半径、均值 CE 需求下，独立评价探针的 DTD CE 变化如下。负值表示改善；这些是有限步观察，不是训练完成后的官方验证成绩。

| 控制 | step 0 | step 25 |
| --- | ---: | ---: |
| 完整梯度 | -0.00780961 | -0.00673827 |
| 锁定的 8 个梯度需求模式内 | -0.00594613 | -0.00536847 |
| 禁止这 8 个模式，使用完整补空间 | -0.00672363 | -0.00577328 |
| 均值梯度一维基线 | -0.00216578 | -0.00162583 |
| 原有 Fisher 4 模式 | -0.00713202 | -0.00615672 |
| 新位置重新构造的 8 模式 | 不适用 | -0.00547177 |

参数半径分别为 0.0004249971、0.0004140383；同一位置内相同，跨位置数值不同。这里的 8 是有限构造需求矩阵的秩，不是对模型内在维数的判断。

当前观察支持“模式内存在有效动作，模式外也有明显可用收益”。它没有证明这组动作不可替代，也没有证明 Fisher 4 模式优于同秩梯度模式——同秩对照要读完整曲线。三类需求的选择探针均选择了完整梯度；结果保留了这一事实。

评价集仅是与构基/选控制分开的训练侧开发图像：DTD 最终评价 94 张，Cars 最终评价 104 张，**Cars 只覆盖 104/196 类**。它们不保证未被专家训练见过。近似区间未作多重比较校正。大范围实验使用覆盖全部类别的更大探针检验这些现象。

## 解释规则

- `fisher_common_objective` 才是相同二次目标及同一半径上界下的比较；`fisher_freeze` 是各自归一到同半径的方向比较。两者分别解释。
- 代理删除代价包含参数正则和预测变化成本，不能称为真实 CE 删除损失。数值区间假定固定精确算子/投影，没有包住浮点算子误差、抽样误差和非线性代理误差。
- 禁止含有构造梯度本身的整个空间后，该梯度消失属于构造恒等式。不能据此声称发现了不可替代的物理参数。
- 专家基线包含凸混合线及两个独立系数的 3×3 网格。匹配半径和原始系数尺度分开；零增量、重复方向均保留。这里只比较局部采样，不是完整 EC 搜索。
- 先导的算子计数按进程累计，恢复后可能重置；不能把某一进程的最后计数称为全部实验成本。`gradient_timing.jsonl.gz` 保留测得的梯度耗时，大范围版本另外记录逐例/跨进程耗时。
- 本轮没有训练新专家，也没有完成“受控训练 Val≥80%”和“EC 优于普通系数搜索”的最终验收。
