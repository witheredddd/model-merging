## 可以怎样使用

可直接检查缩步误差规律、独立功能响应、数值收敛代价、方向增长及子空间变化；也可作为后续预测模型的数据格式样本。当前只有两个完整转移，不足以训练或验证有说服力的 JEPA，也不足以证明低维流形、连续性或在线基优于冻结基。

误差均为比例，乘 100 才是百分比。功能嵌入是逐图像的 `2 sqrt(p)/sqrt(N)`，Log 在逐图像球面乘积上计算。留出 probe 不参与出生与步长接受；完整原 probe 池已部分用于出生，不能将整个池称为留出集。CE/Top-1 仅观察，不作为接受门槛。算子耗时是累计值，不能把每行累计值直接相加。

捕获边界以事务 648 为准。附属观察与数值日志在随后复制，可能略新于该事务；不能将日志最后一行当成已经完成的路径状态。`relative_eigen_residuals` 评价的是 Ritz 向量，经过对齐的列不再各自是特征向量。空间角度同时可能受到数值更新与新增方向影响，不能全部归为曲率。

## 发布边界

**没有上传模型权重、图像、图像 ID 或全参数向量。**完整运行目录约 33 GB，单个全参数向量约 690 MB；它们不适合普通 Git 文件。已接受路径的实际参数、位移与所引用方向仍保存在 A100 原运行目录。历史数值临时方向可能已按无引用规则清理；索引明确记录导出时存在性，其哈希来自历史记录，未在本次对大向量重新计算。

因此本包可独立复算功能预测误差和检查数值状态，但**不能仅靠本包重新加载完整模型、重新执行 JVP，或重建每个历史参数向量**。需要这类实验时必须使用 A100 上的模型与向量。JSON 中 `$RUN` 表示原实验目录，`$RESOURCE` 表示未发布的外部资源。原始文件哈希引用是来源标识，不一定对应路径清理后发布 JSON 的哈希。

## 校验与复算

在仓库根目录执行：

```bash
python verify_hashes.py
python data/self_fiber_flow_DTD_20261119/reanalyze.py
```

第二条命令只需 NumPy，校验本包所有原始导出文件，并从功能数组重算两个完整转移的学习与留出误差，无需 GPU 或模型。
