# v3：任务损失与组条件功能响应共同学习

本版按最新的“分组后”要求实现。分组只提供初值，不用 ARI 或 silhouette 取消多组训练。一个任务只有一个固定预测映射、一个经验商空间和一个共享提升器；功能组不是纤维。

## 核心计算

固定早期锚点 `theta_w`、参数字典 S 及 `A_w=J_w S`。取稳定可达响应基 L，缓存 `C_w` 和小矩阵 `T=C_w L`。在实现中写 `U_m=L Q_m`，所以每组始终处于稳定可达像中。Q 的行数至多等于字典维数，不形成概率环境空间的协方差矩阵。

```text
sum_m Q_m a_m -> L -> combined functional tangent
sum_m Q_m a_m -> T -> dictionary coordinates x
theta = theta_w + S x
```

每次前向生成一个完整模型。第一阶段为 `K=1,B=0`，没有自由高维残差、可训练 D×r 提升矩阵或额外高维 AdamW 写回。

## 交替训练

1. 每个训练 minibatch 更新坐标。采用真实任务 CE、参数信赖域和回溯；一次拒绝只拒绝当前试探，下一 minibatch 继续。连续非零梯度拒绝会恢复探测步长；方向更新后也恢复坐标步长。参数半径边界使用投影，保留可行的切向进展。
2. 收集最近窗口的 `d_j=-L^T C_w^T S^T grad_theta CE`。这是解码器任务伴随，区别于初始化的前向响应 `J_w v_j`。L 仅包含数值稳定的可达方向。
3. 软责任 rho 结合当前覆盖、逐渐衰减的早期方向先验、条件投影能量，以及独立训练批次上的真实组删除 CE 收益。每条响应的责任和为 1；不强制各组等质量，不用正交惩罚制造独立组。相互冗余和责任模糊仍可能存在，必须报告。
4. 响应学习组使用加权响应矩阵的截断 SVD 提议目标子空间，加上任务 CE 的 Grassmann 方向，进行有界旋转。这样可以处理 `a_m=0` 或新方向与旧子空间恰好正交时的零梯度陷阱。方向支撑秩与正则化后的目标秩分别报告，旧方向补齐不算作新响应证据。
5. Procrustes 对齐后，联合重拟合所有组的坐标以重构当前参数位移。超过重构误差、位移、目标局部域、独立训练 CE 或真实 FR 跟踪容差的提议被拒绝。拒绝方向提议不终止坐标训练。

窗口目标是任务 CE、组加权响应残差和相邻子空间漂移之和。实现用初始响应 RMS 做全局尺度校准，记录其等价的原始响应目标系数，不对每条响应分别单位化。CE-only 对照使用相同方向更新窗口和接受规则，去掉响应项；frozen 对照固定所有 Q，只调整坐标。

## 同秩对照

默认总秩为 4、8，每个总秩都实际执行：

- 单组，CE-only；
- 双组（2+2 或 4+4），CE-only；
- 相同双组，加入组条件响应学习；
- 相同双组，冻结方向。

单组和双组从完全相同的联合初始子空间出发，使用同一个 S。每个优化器试探、几何接受、条件收益前向都按训练图像计费。`matched_r*.json` 只在所有方法都达到预先列出的共同预算检查点后报告配对结果，并列出实际模型成本；不宣称 FLOPs 完全相同，也不因单个坏批次自动缩减其他训练。

早期响应重新估计 95% 能量所需秩；历史“四维约 98%”不作为本轮测量或“四个组”的依据。独立可达性检查使用未参与初始字典的训练梯度，分别记录参数投影和功能投影保留率；自字典覆盖接近 100% 不算独立证据。

## 验收与扩展边界

`--control-audit` 提供冻结方向后的坐标复用、正负坐标干预、X/Xprime 真实 J_t 预测检验，以及删除/同秩合并后的补偿训练和全组继续训练对照。有限预算的必要性、端点 CE 和响应覆盖均不能单独证明功能模块已被识别。

`feedback.py` 是小模型/小探测上的完整可微反馈提升参考：每步右端取真实当前预测到下一个目标的球面 Log，Jacobian 随当前参数变化。完整模式通过自动微分保留 dA 和当前预测反馈两类导数；停止 A 梯度的模式明确标为近似。测试验证非线性共享解码通常不等于各组分别解码后的和。

B 只表示目标功能图二阶曲率。`curvature.py` 要求二次设计可辨识、独立轨迹收益、字典局部二阶相容性和已验证非线性解码器，才允许启用；W 不被硬限制在一阶 Jacobian 像中。B 不是实际解码图第二基本形式的自动估计。主训练尚不启用多步或曲率，也未宣称全规模 CLIP 多步高阶反向已完成性能验证。

`dictionary_refresh.py` 是未自动启用的固定秩扩展：持续的字典外任务证据、保护当前参数、重新计算提升算子、重构与独立 CE/FR 验证均为事务前提。默认运行固定 S，因此不声称已经实现高维参数跨度的持续演化。没有“失败就出生新组”的入口。

## 运行

需要相同 CLIP ViT-B/16 基座、固定头、48 个视觉权重矩阵和既有 DTD 划分。初始化可以复用上一版只含 100 步预热和早期候选的缓存；不读取 4000 步专家终点。缓存尚不存在时，可用历史 r2 的 `--phase initialization` 只生成早期输入，其分组诊断不作为 v3 训练门槛。

```bash
python -m unittest discover -s scripts/fisher_rao_response_v3 -v
python scripts/fisher_rao_response_v3/runner.py \
  --root /home/shangxueyuan/merging/tsv \
  --early /media/shangxueyuan/data1/fisher_rao_v2_internal_groups_20261112_r2 \
  --output /path/to/new-v3-results \
  --seeds 11 23 37 53 --ranks 4 8 --attempts 64 --window 8 --budget 16000 \
  --control-audit
```

不得在源码哈希改变后直接恢复原结果目录。输出包括明确停机原因、拒绝原因、rho、每窗独立条件批次 ID、真实几何轨迹、重构误差、方向角度、冗余和实际成本。

21 项测试覆盖梯度、响应目标、零坐标、正交新方向、坐标重拟合、病态提升算子的几何回溯、恢复、边界、冻结控制、字典保护、二阶相容性和反馈伴随。A100 真实 CLIP 小样本联调跑完四种入口各 9 个 minibatch；它只验证接口、计费及梯度，不证明组有独立科学作用。测试集、纤维学习和 EC 均不自动启动。

第一轮完整 DTD 联调揭示，固定五档几何步长在病态提升下全部因参数重构误差被拒绝；已改为配置控制的 12 档几何回溯，仍保持原 CE 和 5% 重构阈值。旧联调源码与结果另行保留，不以该联调宣称响应演化成功。
