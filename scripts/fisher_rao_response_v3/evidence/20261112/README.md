# Implementation acceptance, 2026-11-12

These are short, single-seed integration checks, not a successful scientific validation of identifiable groups. DTD uses the installed training mirror and registered development splits. The official test set was not opened. No weights, datasets, raw user attachments, or credentials are included.

- `rank4_report.json`: real CLIP ViT-B/16, 48 active matrices, X=512, seed 11, total rank 4; each of four controls completes 16 coordinate minibatches and four geometry windows. Response geometry accepts three windows, with bounded rotations, real CE checks and joint coordinate refitting.
- `rank4_verification.json`: source hashes from the executed configuration, independently compared with the installed source, and actual response-window acceptance diagnostics. Accepted reconstruction errors are below the unchanged 5% limit.
- `matched_rank4.json`: development results at the predeclared common 1024 charged-training-image ceiling. Exact selected/prefix costs differ and are recorded; this is not a FLOPs equivalence claim. Single-seed sample bootstrap does not establish replication across training seeds.
- `clip_smoke_report.json`: earlier isolated small-probe interface and adjoint check, before the final geometry-backtracking refinement. X=8, S has four columns, rank 2, nine minibatches per case. The task-adjoint relative error is zero. This smoke result does not support a claim that response-driven geometry always moves.
- `rank8_report.json`, `matched_rank8.json`, `rank8_verification.json`: all four rank-8 controls complete 16 minibatches; response geometry accepts one of four windows. The frozen-coordinate reuse, both compensated deletions and the same-rank compensated merge all execute. The 64 signed coordinate interventions on X/Xprime have minimum true-J_t cosine 0.999969 and maximum relative error 0.00813. The short same-rank merge CE-cost interval includes zero, so this check does not establish independently necessary groups. Deletion also reduces total rank and must not be interpreted as a same-capacity superiority result.

An earlier full-X check rejected every response geometry proposal because a five-level angle search never reached a model-preserving step. Its output and executed-source archive remain on the server. The corrected optimizer uses 12 levels and an ill-conditioned-lift regression test; CE and reconstruction thresholds were not relaxed. The 21 numerical/regression tests pass. The executed main model remains K=1, B=0 with fixed S; nonlinear feedback, curvature authorization and fixed-rank dictionary rotation are explicit separately tested extensions, not advertised as full-scale training results.
