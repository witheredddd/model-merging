# 参数保护性机制：条件图、选择性模式与剩余接口

主要评价对象是合并后的联合控制。每个局部图不需要单独完成整个需求。同空间最优值相同只作坐标等价性校验，不作补偿失败或成功的证据。新增固定驱动振幅下的补偿前后代价、目标响应变化，以及合并提升空间的全谱联合控制曲线。曲线列出所有谱前缀，不自动选维数，不设置累计解释率门槛；仅反映已有区域方向的表达能力，跨需求和位置复用仍需独立证据。

曲线明确分开：`complete_prefix_curve`是固定权重WLS折中，不是固定响应保护最优或完整Pareto前沿；`fixed_response_prefix_curve`对同一指定y逐项求严格等式最小保护加正则代价，不可达明确标记，不用较弱目标响应替代。基准是完整已观测区域空间，不冒称完整参数空间最优。固定驱动报告同时给出补偿前后相对指定y的误差。

`cross_target_demand_reuse`在相同冻结物理区域方向、相同样本上改变目标任务，对比冻结补偿及模式、重算补偿但保留模式混合关系、重算补偿及选择性谱。三者在同一个新需求下评价，WLS和严格响应结果分列。这是有限需求族的跨目标测试；**不是跨参数位置实测**。`combined_reuse`要求物理基身份一致；若新位置只提供自己的局部区域方向，拒绝将系数当作冻结结构复用。跨位置必须先对同一批冻结参数方向计算新Jacobian响应，目前未宣称完成。

观察器缓存每次核对实际区域文件、源控制向量、配置和源码哈希；观察索引不变但数据被替换也会重算。已增加全谱终点等于完整WLS、可逆换基不变性及数据替换失效测试。主学习进程无需更改。

现有共享残差空间是完整条件运动的数值基线，**不是已经发现的保护性参数组**。本模块补上可计算的保护机制链路，不使用K-means、Top-K、固定组数、模式数或解释率截断。自动支持发现的唯一规则尚未建立，不能把本模块的候选支持当成最终组成员。

`conditional_graph` 接受任意多个驱动坐标，显式构造保护与参数代价A的T=-A_NN^-1 A_NM、L及S=L^T A L，再对提升后的目标Fisher与S求广义谱，保留所有数值可解轴。模式为b=L u，输出驱动与补偿来源和功能能量。这是声明的采样坐标上的受限Schur；一根区域运动向量不等于该区域的全部参数自由度。

`ArbitrarySupportSchur` 提供完整参数补偿接口，支持跨张量的非连续索引、布尔掩码及切片，补偿端保留全部其余参数。它扩展原数值原语，不改变旧切片算子的数学目标；迭代误差仍须报告。

`mechanism_report` 在相同y下分别求原始采样空间、单独驱动、保护提升与选择性模式的严格等式条件最优控制；不可达明确报告，不偷偷换成WLS。软WLS另列。删除区域的比较会重新优化所有剩余坐标，不以简单清零冒充必要性。

`metric_split` 在明确的A_P度量下将更新投影到已验证模式，并输出剩余功能响应及各任务交叉项。A_P正交不等于各任务分别正交。该接口不运行EC；只有模式保护性和目标保持得到验证后，才可把剩余部分交给后续EC。

`observe.py` 只读已有真实区域响应，持续生成受限补偿图与联合模式的系数、源运动文件及哈希。每个已观测非零区域作为条件探针，其余已观测区域允许补偿；这是一组机制对照，不是按单张量限制学习器容量。API另外支持多区域、多驱动坐标，测试覆盖三维驱动。尚未观测的区域不被称为不必要成员。

对照的固定目标是当前已观测区域运动合成的实际目标响应，保证在该有限原始空间可达。它不能替代原始任务需求的完整参数最优基准。报告包含可重建b=L u的来源、系数与作用范围；自动分组、全参数保护性验证和EC融合均未宣称完成。

运行：`python -m unittest -v`；`python observe.py --source EXISTING_DIAGNOSTIC_OUTPUT --output NEW_OUTPUT --watch`。

本模块与原学习进程独立，保留所有现有候选和17个真实训练位置；不写回训练参数，不要求CE或准确率改善。
