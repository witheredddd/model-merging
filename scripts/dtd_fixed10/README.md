# Two different fixed-10D tests

Follow-up **inference-only transfer projection**: [82.07% external expert report](evidence/20261113_external_expert/REPORT.md). Keep the old Fisher basis unchanged and project a different expert, without training: historical Test accuracy82.0745% ->49.2553%. The active48-only expert control retains82.2872%, ruling out the scope mismatch as the main source of this drop. This does not compare Fisher selection to PCA or random subspaces.

Completed A100 experiment: [report and paired results](evidence/20261113/REPORT.md). Both training arms completed128 updates. Fixed10 final Xprime accuracy51.5625%; full AdamW final72.265625%. Projection preserves all640 development predictions. These different findings must be reported separately.

Use the top10 eigenvectors of the mean of individually Frobenius-normalized DTD Fishers at steps16,48,80,112, within the previously measured26D common computation space Q. This exactly reproduces the reported99.99983641185109% squared endpoint-update coverage (up to finite precision). B10 is Euclidean-orthonormal in parameter space; it is fixed throughout the experiments. No Grassmann update, regrouping or fiber step is performed.

1. **Projection reconstruction.** Compute theta0+B10B10^T(theta128-theta0) in FP64, materialize FP32 weights, and compare with the exact original FP32 theta128 on identical Vcal128 and Xprime512 IDs. Report CE, accuracy, prediction agreement, mean KL and maximum sample CE difference. Norm coverage alone is not evidence that task learning requires ten fixed degrees of freedom.
2. **Restricted training.** Start again at theta0 with all ten coordinates zero; optimize true CE using only theta0+B10*a for128 steps of32 images. B is never updated. A separate full-parameter AdamW control uses the same base, batch IDs/order and128 updates. Fixed10 coordinates use AdamW LR0.01; the full-dimensional control uses LR1e-5. Both use zero weight decay. These rates are predeclared and differ because of coordinate scaling; no LR sweep or matched-FLOPs claim is made. A failed optimizer setting does not prove fixed-space incapacity.

The active scope is the original v5 trajectory's48 visual matrices, frozen head and other weights. Source data is the frozen v5 training/development protocol. No official test data. Select each trained arm's checkpoint only by Vcal CE every8 steps; report both final and selected models on Xprime. The basis comes from the entire previous trajectory and endpoint: this is a **history-informed fixed-space capacity control**, not an online structure-discovery algorithm or a fair data-independent learning method.

Each arm retains a full resumable checkpoint every8 steps (coordinates or full weights, optimizer, step, source/assets/split identity, IDs/events and best selection). The multi-GB fixed basis is saved once, referenced by checkpoints, and remains on A100. The step-deterministic input sampler reproduces IDs and augmentations after recovery. On SIGTERM save after the current step; a hard interruption replays work after the last checkpoint. A100 allocation is capped at30%; existing GPU jobs are not modified.

Two CPU tests check orthogonal projection and the real decoder's coordinate-gradient chain rule. Real-task success is determined by actual reports, not the test count. Raw bases, checkpoint weights and per-sample logits are not publicly uploaded by default.
