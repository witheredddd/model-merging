# 同一功能目标下的条件空间辨识

## 当前入口：adaptive.py

`adaptive.py` 继续已有共享空间与CG状态，旧 `runner.py` 保留为上一版数值基准。旧单张量Schur基准不再是学习前置步骤；`--relative-error-budget`只保留旧检查点配置兼容，不作为当前学习准入标准。

当前每个调度回合执行一个可恢复求解批次或一项独立诊断。未满足旧0.1%预算的有限候选也会产生带误差界的观测。空间缺口、候选功能收益和源运动误差是否足以改变相应判断，决定后续细化优先级；某条件的数值停滞被单独记录，不阻塞其余条件。

参数残差只是候选。新增分量先在相同WLS中计算加入前后的目标值、目标误差、保护泄漏与参数正则变化；无可分辨功能收益的独立参数方向不进入当前空间。没有收益百分比门槛，只有小矩阵浮点比较误差；源求解的不确定性以连续可信度及暂定状态记录，不冒充可靠功能组。

学习、源模式重生成、独立probe验证、针对性细化、逐参数区域功能诊断交错执行。先在各位置覆盖全局任务需求，再轮转类别需求；不要求在第0步穷举1532个需求才访问下一位置。调度份额不是模式维数限制。

跨位置采用**在当前Jacobian下重新运行同一需求生成机制**。不加载旧位置的切向量作为新需求，不称为固定切向量的平行运输。当前点的动态空间、升级时冻结的完整空间、全部历史坐标累积空间分开保留与评价；每个位置持久保存已演化的空间和所有已重生成来源，后续访问继续更新。

独立验证逐项使用原功能需求生成机制及类条件请求，不再固定使用0.37/0.63混合；验证参考不加入空间，也不用于选择维数。数值参考仍可能有限精度，比较随附误差区间。

`streaming.py` 用固定I/O块流式计算参数内积、残差及磁盘向量组合；增量Gram只计算新增行列。全参数矩阵不拼成D×r，GPU只处理当前一个完整向量。I/O块大小限制临时工作内存，不限制模式数。空间文件和小Gram仍随实际发现的结构增长，其成本需要持续记录。

参数区域诊断对一个实际受限最优运动遍历**所有**原生参数区域，测量各区域任务JVP、保护交叉项和移除单区域的线性反事实代价，并校验区域响应之和等于完整运动响应。这是实际功能补偿读出，原生区域不决定新方向支持，也不等于已经自动发现稳定耦合块。诊断逐区域断点执行，不阻塞其他需求。

恢复指纹覆盖CORE、LEGACY、R3、SPACE及已导入的项目Python模块，并记录第三方版本。首次扩大依赖指纹覆盖范围会显式记录，不能据此反推过去未记录文件的历史身份。

```bash
python adaptive.py --old PAUSED_OBSERVATION --source ORIGINAL_PROTOCOL \
  --trace NORMAL_TRAINING_TRACE --coordinates PARAMETER_ORDER \
  --output EXISTING_DIAGNOSTIC_OUTPUT --quantum 4 --gamma 0.1 \
  --block-elements 262144
```

从上一版恢复须先保存退出并明确记录源码迁移，保持现有CG和向量数值不变。真实维度的流式测试及运行耗时另存在私有实验输出，不随源码发布。

以下描述为历史 `runner.py` 基准的行为；其统一预算和串行目录调度不再是当前入口的规则。

本入口替代 `functional_space_20261117` 的单张量/单方向/四步后推进机制。旧结果保留为历史对照。本阶段固定已有普通训练轨迹、模型、探针及任务配置，不新增训练更新，不以CE或Top1作为接受条件。

## 数值与结构分开

`--quantum 4` 只规定检查点批次。保存CG的x/r/p/rr并在相同条件继续，直至新计算的正规残差给出的参数和功能误差界满足可配置预算。没有总迭代次数上限；数值停滞或曲率异常会保留候选并停止，不能作为可靠结构推进。默认0.1%预算用于分辨小于一个百分点的差异，不代表严格条件最优认证。

首先在第0步恢复旧DTD完整WLS与保护补偿CG状态，验证相同需求、probe、权重、参数度量和原始参数位置。保存每批参数变化、任务响应变化、真实残差、误差界与目标值。重新评价旧单模式只是解释旧实验，不是新结构容量的规定。

每个评价同时报告完整有限精度参考的目标误差、同一WLS下未衰减受限最优的响应重构误差与需求误差、单独的衰减观测、各任务保护能量、参数正则代价、WLS目标差和带参考误差界的最优差区间。Euclidean投影另列。

## 空间学习不预设维数

所有目标任务和需求族共享同一个控制坐标空间。先用已有空间承担新需求，再细化完整空间参考，以 `v_ref-P_B v_ref` 的全参数残差发现缺失自由度。两次投影去除已有成分，数值独立且超出求解误差的残差才加入坐标。保留来源和残差构造配方；不按最大原生张量选支持，不设置模式数量上限、固定解释率或99%截断。

这些坐标仍是待检验的条件运动分量，不能直接称为功能组，也不能把追加后重构本需求成功当成可复用低维结构的证据。每个位置从八任务×两种全局参考需求开始，再按实际探针类别展开类条件功能需求；16个初始需求不是秩上限。在离开位置前，另用不相交probe上的功能需求评价整个冻结空间，验证参考不写入学习空间。跨需求、跨任务、独立probe和跨位置表现必须分别报告。完整类别目录的计算量较大，实际覆盖量和耗时要如实记录。

原生张量仅用于连续能量读出，不决定结构容量或成员。保存跨坐标的各任务功能二次型及参数Gram；未声称这些读出已经完成参数区域的功能成员发现。坐标向量采用CPU mmap、逐列计算JVP，GPU容量不是模式数量限制。

## 位置与重定位

17个普通训练记录逐文件校验并保持原样。原记录来自原普通训练配方的重放，末端与原专家逐张量一致；不声称独立认证原始训练每个未保存中间步。

完成第0步完整需求族学习和独立验证后，在第25步冻结**全部**已有坐标，并重定位全部坐标后对比。重定位沿每个残差坐标的原构造配方：在新Jacobian下求同一源功能需求的联合WLS，再减去重定位的父坐标，保持原坐标尺度。它叫联合条件运动重定位，不冒充纯保护Schur补偿。旧单张量基准仍可独立研究纯保护T。

在同一个新位置、新需求、相同权重下评价冻结与重定位整个空间；源需求在重定位过程中固定。随后在每个其余真实位置执行完整需求族与独立probe验证。新位置新需求的适应评价与固定响应运输有不同定义，不混用名称。

当前是历史轨迹上的离线机制研究。`normal_response`使用已保存的相邻位置；不是声称可在真实在线训练时访问未来位置。识别流程不改变轨迹下一位置。

```bash
python -m unittest -v
python runner.py --old PAUSED_OBSERVATION --source ORIGINAL_PROTOCOL \
  --trace NORMAL_TRAINING_TRACE --coordinates PARAMETER_ORDER \
  --output INDEPENDENT_OUTPUT --quantum 4 --relative-error-budget 0.001 --gamma 0.1
```

gamma=0.1与I参数度量保留用于同条件诊断。采样需求及位置是实验覆盖范围，不是结构维数上限；样本跨度和观察坐标数不足以证明内在维数。验证尚未完成时，不报告低维假设成功或失败。
