# 保护补偿图与真实模式控制 r3

本实现针对 `de40b25` 的目标一致性审查重构。旧r2源码与全部实验状态保留；r3不是将Krylov字典改名为功能组，也不把CG加速当作结构学习目标。

## 数学与执行链

1. 显式选择完整参数WLS：`min_v 1/2 vᵀ(F_P+rho I)v + 1/2 ||J_Tv-y||²`。严格等式原语单独保留；不可达时不会偷偷使用词典序替代。
2. 需求采用归一化负CE余切，满足 `J_Tᵀ y=-grad_CE/s`；这是明确改变的需求族，不与旧CE单位参数梯度JVP或专家JVP混称。WLS不要求该需求可达。参数度量I、目标响应权重I、原谱单位gamma族均是本阶段显式设置。
3. 得到完整空间运动后才按原生张量展开，选择一个待探索的驱动支持M；N为全部其余参数。候选支持不预先限制完整求解域，也不设驱动、补偿、组数或最终模式数上限。支持排序属于表示探索策略，不能称为唯一分组。
4. 构造真正的参数支持补偿作用 `T x_M=-(F_P,NN+rho I)^{-1}F_P,NM x_M`。算子接受任意驱动坐标向量。实际只计算已查询的作用，保留数值误差；不声称已枚举整个高维图空间。
5. 由 `L x=E_Mx+E_NTx` 的已探索列构造每个图自己的选择性广义谱，最终每个模式都保存 `b_j=L_graph(j)u_j` 来源。谱轴实际参与控制解码，不是认证后日志。所有可解析谱轴保留，不按能量百分比或固定维数截断。
6. 在模式振幅上解同一个联合WLS。模式不确定性进入显式执行算子 `z_exec=D H^{-1}D rhs`，D由连续误差可信度构成；它与未衰减的WLS最优系数分别报告，不把执行衰减伪称为原目标最优解。一个不可靠模式不会禁用所有其他模式。
7. 用真实CE与同一非线性WLS功能代价的Armijo搜索检验 `Delta theta=Bz`，接受后持久写入完整参数点，保存实际接受的alpha和实际振幅。未提供硬保护预算时不声称正则化自动满足任意预算。
8. 在新锚点重新加载模型并重算补偿作用，记录T的作用如何改变。已有图在后续调度中先尝试真实控制，失败再回完整空间发现。这里实现离散位置更新，未声称实现连续ODE。

## 数学对象与模块

| 模块 | 责任 |
|---|---|
| `control_math.py` | 严格可达原语、联合WLS、尺度无关的数值表示、图内选择性谱、误差加权执行 |
| `operators.py` | 完整空间WLS输出对偶系统；另立参数支持Schur/T作用，支持一般度量交叉项的参考实现 |
| `worker.py` | 候选运动→条件图→谱模式→真实写回→新锚点重建的生产状态机 |
| `cache.py` | 按字节管理派生缓存；逐出不删除模式或结构历史 |
| `finite_control.py` | 同一功能目标下的真实模型有限检验，记录七任务泄漏和实际CE/Top1变化 |
| `io_state.py` | 不可变事务、独立求解断点、原子锚点提交、公平且代价/误差/信息感知的调度 |
| `evolution.py` | 固定局部图的模式振幅接口，目标为实际八任务归一化Top1向量；需要显式提供原归一化因子 |

EC适配器有目标一致性测试；本轮先验收真实几何控制闭环，不把接口存在写成已完成Pareto融合搜索。

## 误差如何影响控制

对于显式正定WLS算子 `H>=rho I`，使用重算的原始正规方程残差r，得到 `||e||<=||r||/rho` 和联合能量误差上界 `||e||_H<=||r||/sqrt(rho)`。补偿端同样有完整N域的强凸界。由此构成连续可信度，参与来源调度和每个谱轴的实际振幅。不是从KKT相对残差直接推出任务响应误差，也不是恢复“先认证再学习”。这些是给定计算算子下的解析界，不是包含所有浮点/导数误差的区间认证。

旧方向不按owner无条件删除。驱动观测完整保留，仅对归一化后的驱动表示做小坐标数值独立性检查；没有用完整P乘机器epsilon作为结构出生阈值。历史驱动在新位置重新应用T，不能把旧锚点的误差解释成新锚点的误差。

## 验证与运行

```bash
python -m unittest discover -v
python worker.py --source OLD_PAUSED_OUTPUT --output INDEPENDENT_R3_OUTPUT --work-quantum 4
```

`work-quantum`是一次观测前分配的数值迭代量，可以接续，不是总求解上限或结构维数上限。真实模型需原A100的完整参数、训练侧数据、模型资源和协议；不随源码发布。参考求解、补偿重建、控制和真实验证的时间分开记录。

测试覆盖不可达满列秩目标的保护权重效应、严格可达解、完整空间求解与误差界、一般SPD度量交叉块、目标曲率不混入保护补偿、Schur能量恒等式、尺度不变性、历史保留、谱实际参与控制、误差改变执行而不整组禁用、公平调度、缓存逐出、恢复不重复施加更新，以及带非单位alpha的生产写回与新锚点重建。

## 实验解释边界

首次图可能只含一个已探索驱动方向，这不是预设一维控制，也不能证明低维性。样本图内的谱构造不是完整高维谱已穷尽；多个候选图不被当成唯一分组。研究是否成功最终取决于可复用的条件控制、保护代价、有限功能与真实Pareto表现，不能以模式数、机器秩或测试数量代替。
