# v3 的预算、几何拒绝与功能控制诊断

本轮回应对 `9b4ff39` 的审查，不增添算法模块。主模型保持一个固定任务预测映射、共享 K=1 水平提升、B=0、固定早期字典 S。没有纤维优化、字典刷新、曲率训练或 EC。M=1/2 仍是对照假设，不是任务自动发现的组数。

## 冻结协议

- DTD，48 个视觉矩阵，原训练/开发划分，X/Xprime 各 512；不打开官方测试集。
- 种子 11、23、37、53，总秩 4、8，各自比较单组 CE、双组 CE、双组响应、双组冻结，共 32 个主实验。
- 每个方法真实消耗 **16384 张计费训练图像**。梯度、线搜索及几何条件收益前向都计入；不以空操作补齐预算。坐标 minibatch=32，每窗最近 8 条响应。至少 64 个坐标 minibatch；若预算耗尽前未满足，程序直接报协议失败。
- 每消耗 512 张计费图像，保存当时已接受的实际模型并评估同一个 Vcal。1024、2048、4096、8192、16384 处分别报告即时模型和此前统一网格上 Vcal CE 最低的模型。两者是不同估计对象，不再用选优结果冒充即时结果。
- 精确成本边界可能在一次梯度计算后到达，此时没有余量试探，模型保持当前值，优化器不会把预算耗尽误判为坏方向而衰减步长。临近边界不足以做一个几何试探时，将窗口延后。此边界规则对所有方法一致。
- 预先指定开发种子 11、23 额外真正重训响应方法的 1%、20% 参数保持容差；默认 5% 及 CE 非劣阈值 `1e-6`、FR 规则不变，共 8 个敏感性实验。不会用该结果改动种子 37/53 的设置。

`budget_report.json` 以四个训练种子为配对单位报告差值及描述性 bootstrap 区间，保留每个种子的值。只有四个种子，不能将样本级 bootstrap 当作训练种子的复现证据。

## 几何拒绝诊断

主训练完成后，重放每个默认响应方法的每个几何方向提议，恢复同一批样本、增强随机种子、旧组、坐标及有界切向提议。在 12 档原角度网格上计算真实 CE、参数误差和完整固定 X 上的真实 FR 跟踪；比较 1%、5%、20% 容差下可接受的最大已测角度。结果称为“已测网格最大值”，不宣称连续空间全局最大值。

离线评估不能反向影响主训练或选择模型，其前向成本单独记录。它能区分重构约束、CE、联合响应目标及 FR 条件；同一状态的反事实不等于改变容差后重新训练，真正重训的敏感性组另行报告。

## 功能控制与同容量对照

单组、双组 CE、双组响应均在最终统一 Vcal 选择的模型上审计：

- 将每组提升后的参数方向正交归一，计算实际 J_t 在相同 Xprime 样本上的响应能量。报告按类别的响应、正负干预下的类别 CE 变化及真实 JVP 误差。
- 同一联合空间随机旋转后再划分，作为响应差异和跨种子匹配的参照。原组正交本身不计作任务功能独立性证据。
- 通过相同样本上的响应指纹做跨种子匹配，不比较不同锚点下的任意基底列。高匹配分数仍可能来自共同样本难度，因此同时报告随机划分参照。
- 默认响应模型继续训练 2048 张计费图像作为全组对照。删除一个组后，用新方向恢复原总秩、替换组坐标从零开始；独立比较两种删除。另有同总秩合并并保持当前模型的对照。所有继续训练使用相同额外成本及两种选择规则。

该有限预算补偿仍不是可辨识性定理，类响应差异也不等于语义模块发现。结果支持或否定组结构均应如实报告。

python -m unittest discover -s scripts/fisher_rao_diagnostics_v4 -v

28 项数值/协议测试覆盖原 21 项及新增预算、重放、同容量和跨种子检查。运行结果另附，不把测试通过写成多组优越性成立。
