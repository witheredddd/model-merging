# 八任务联合 Fisher–Rao 图流形

## 当前定义

`graph_geometry.py` 实现图嵌入 `Gamma_e(theta) = (sqrt(e) * (theta - theta_ref), Psi(theta))`，其中 `e > 0`。参数分量使用当前视觉坐标的欧氏内积。任意固定参考点都给出相同的切映射 `A_e(v) = (sqrt(e) * v, Jv)`。图切空间的拉回算子为 `A_e* A_e = J*J + e I`，并满足 `<v, G_e v> >= e ||v||²`。若后续确定参数坐标的归一化，需在同一坐标约定下解释 ε。

`validate_graph_a100.py` 使用真实八任务、全部共享视觉参数和锁定探针核验图嵌入及拉回恒等式。实验参考点取 anchor0 的 step004，`epsilon_fixture` 是恒等式核验用值。研究用 ε 留为必填正参数。

## 图投影核验

`audit_projections.py` 复用同一检查点和探针锁，在两种输入度量下分别校验六个中心差分步长及独立的伴随内积。每种度量选取联合误差最低的一个共同步长，在该档检查联合误差和八个任务的最大误差。定标记录梯度、专家更新与投影方向的 Rayleigh 商。参数归一化是锚点 RMS 的全局单位变换。四组高 ε 核验基线取 32 个测地和 CE 梯度 Rayleigh 商的中位数。

求解器以矩阵自由 FP64 CG 计算图切空间正交投影，并独立用真实 JVP/VJP 复核每个任务的线性系统残差、投影正交残差和勾股误差。各组保存参数方向、预测响应、可达率，以及由完整图向量和参数侧分别计算的 Gram 矩阵。

运行方式为 `audit_projections.py <无阻尼阶段的来源目录> <新的输出目录>`。结果入口为 `derivative.json`、`scale.json` 和 `results.json`，逐组产物保存在各自子目录。服务输出的 `status.json` 可用于查看当前阶段及实际求解进度。

## 局部更新定标和 ε 预扫描

`calibrate_updates.py` 从 DTD、Cars 的真实训练快照恢复早、中、晚三个已保存相邻区段的参数差，并在同一 anchor0 step004 计算八任务联合响应。anchor0 自适应过程的两段更新单独做对照。临时参考尺度由 DTD、Cars 配对数据定标，两任务与两类方向分别等权，完整的任务覆盖留在 `reference.json`。

`scan_epsilon.py` 用完整任务梯度起始块构造共享 Krylov 基底，所有 ε 复用 JVP/VJP。默认预算为一块，`--max-blocks` 可追加 Fisher 像方向，`--case` 可指定单组。达到各档完整空间残差阈值后提前结束。输出分别验收约化残差、从完整残差重新点积得到的 Galerkin 正交性，以及完整空间残差。候选 QP 另验收求解状态、对偶间隙、KKT 和活动集阈值敏感性。

通过 Galerkin 验收的行记录完整 Gram 元素误差界、单位 Gram 元素区间、最小特征值区间及可达率和原始凸包距离区间。界使用实测残差和交叉项，假设 FP64 联合导数和残差计算准确到报告精度。只有逐项确认权重严格为正或为零时，才记录精确最小面。五档比较位于 `stability.json`。

`residual_relative` 是完整方程残差，`projected_full_residual_relative` 是从完整残差独立点积得到的 Galerkin 正交残差。为兼容结果读取器，`orthogonality_residual_relative` 与后者保存相同数值。区间一致性单独验收。距离下界同时报告区间宽度和相对 FP64 工程误差底线的裕量，该底线不包含对模型浮点算子的严格舍入误差分析。

可用 `--independent-probe-source <未裁剪的原始双探针清单>` 复验第二批数据。入口校验清单哈希和两批 ID 不重叠，从第二批选取与第一批相同的逐任务样本数并重新验证类别覆盖。检查点和 ε 网格来自同一原始协议，独立复验重新计算 JVP、VJP 和任务梯度。结果协议记录选定探针、实际样本数、SciPy 版本和直接依赖源码哈希。

带双探针清单时，`--source-probe 0` 或 `1` 指定构造方向的批次。入口核对每个任务逐类别样本数。约化 QP 只用来源批次。方向按来源批次的图范数归一化，随后用目标批次的八个 VJP 内积直接检查同一个 (v)。`report_probe_transfer.py` 汇合双向结果，逐档对照旧第一批证书并导出公开报告。公开协议保留源代码指纹、样本数与检查结果，模型和数据资产路径留在原始协议中。

运行时保留 `preview.json`、`stability.json` 和 `protocol.json` 原件。第一批报告中的 `certified_scan.json` 和 `certified_stability.json` 分别对应单块运行的 `preview.json` 和 `stability.json`；`block2_stability.json` 对应双块运行的 `stability.json`。

## 运行依赖和资源锁

FP64 路径复用仓库的 `scripts/eight_task_coupling_20261116`、`scripts/fullspace_conditional_20261116` 和 `scripts/fr_hst/task_data.py`。需要 CUDA、PyTorch、torchvision、open_clip_torch、NumPy、SciPy，以及对应的八个训练数据集、预训练权重、八个专家与分类头、坐标清单、检查点和探针锁。原数据、权重和私人运行产物保存在实验环境。

`TSV_ROOT` 可指定项目根目录，`TSV_COORDINATES` 可指定坐标清单文件。加载时先校验工作点、清单、探针锁及专家和分类头的 SHA-256，再加载模型。预训练权重与坐标清单中的基准哈希核对。运行协议记录实际运行时源码、依赖版本和变换后探针张量的指纹。

## 无阻尼对照记录

首轮使用已有 ViT-B/16 anchor0 的 step004 检查点。八个分类头保留各自的类别坐标，导数覆盖共享视觉模型的 86,192,640 个参数。实验固定模型，只计算这个参数点上的一阶几何。

## 经验度量

两种权重使用同一批锁定训练侧图像。每类取一个样本。原频率设置给类内样本分配该类在训练集中的频率，类别均衡设置给每类分配相同质量。两种权重均按任务再乘以 1/8。原频率设置是按原类别频率重加权的探针估计。

对于样本权重 `w_ki`（每个任务的样本权重和为 1），实际计算的联合坐标为 `sqrt(w_ki/8) * 2*sqrt(p_ki)`。同一权重乘在对应的理想方向和微分上。该坐标下直接以欧氏点积计算 Gram 矩阵和任务间响应。

## 投影与独立核验

`run.py` 对每个目标解 `min_v ||J v - B_k||²`。它使用 FP64 的 JVP / VJP 和零起点、无阻尼的 CGLS。八个联合响应按任务区块保存。JSON 中保留相对正规残差、原始和单位方向多胞体、候选可达率和 8×8 的响应范数。首轮用了两轮迭代作为计算探针，每个顶点是否达到求解阈值由相应的残差记录给出。

`adjoint_certificate.py` 求 `h_k = J* B_k`。对任意共享参数方向 `v`，`<B_k,Jv> = <h_k,v> = <Π B_k,Jv>`。因此可以在精确投影求解之前，以八个点积均为正的实际 JVP 见证共同下降。若八个 `h_k` 的 Gram 正定，八个精确投影向量线性独立，凸包仿射维数为七。数值输出同时提供 Gram 谱和 JVP / VJP 一致性检验。

`certify.py` 只接受 `run.py` 的无阻尼输出。它把实际 JVP 响应转入同一加权坐标，再将目标投影到已计算响应的张成空间。由此得到的是完整无阻尼可达率的下界。任一单位可达方向的最小任务内积也是完整凸包距离的下界。上界由原始目标凸包和正交投影的范数收缩给出。五档图投影的认证由 `scan_epsilon.py` 负责。

## 复算

在 A100 的项目环境里用 `run.py --help` 查看参数。首轮产物的 `protocol.json` 记录检查点、探针、实验源码和运行时的哈希。输出目录需要是新路径。A100 上的 FP64 运行依赖项目既有的八任务加载器及完整视觉参数微分。
