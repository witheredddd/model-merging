# DTD 提前接入、分量出生惩罚和专家端点控制

训练沿用 CLIP ViT-B/16、DTD zero-shot 分类头、seed 42、完整视觉编码器和 216 次更新。3760 张训练图像全部参与训练。1880 张历史测试图像只用于训练结束后的评分和端点扰动读数。没有重新划分验证集。

前 35 步累积五个初始化窗口，窗口结束于第 7、14、21、28、35 步。几何动力学从第 36 步进入实际权重更新。出生仍要求两个连续训练批次都通过同参数范数对照。在既有门槛上加 0.0002 CE，分别相当于上一轮两次出生确认步的原始收益 0.03547 和 0.01561 的 0.56% 和 1.28%。两个批次各自满足

\[
\mathrm{CE}_{\rm current}-\mathrm{CE}_{\rm candidate}
>\max(10^{-5},0.02|\mathrm{CE}_{\rm zero}-\mathrm{CE}_{\rm current}|)+0.0002.
\]

候选 CE 还须低于零更新的 CE。分量数计算上限设为 5。

## 训练结果

完整新版专家在历史测试集得到 1482/1880（78.83%），CE 0.790925。原版完整专家为 1488/1880（79.15%）。第 36 至 216 步共 181 步有非零几何更新。出生确认发生在第 57、81、105、129 步，最后一次达到计算上限，因而无法从此次运行推断出生惩罚本身会在哪个维数停止。训练末端抽样 Fisher 阈值秩为 7，坐标维数为 10。全量专家位移范数为 0.607298，映射尺度 \(s=0.0384892\)。

## 完整专家端点扰动

对原版和提前接入版各自的完整专家，固定最终轴向量、坐标 \(z_T\)、二次系数 \(q_T\) 和尺度 \(s\)，计算

\[
\theta_T(a)=\theta_T+s[\Phi(z_T+a)-\Phi(z_T)].
\]

零扰动核验完整历史测试集 logits。每个非零方向的精确二次映射位移按 \(\|\theta_T-\theta_0\|_2\) 的 0.5% 和 2% 对齐。诊断时从同一训练集固定选取两组各 32 张图像。组 A 计算 \(G_A=U^\top F_AU\) 和 \(b_A=U^\top g_A\)，其中 \(U=sD\Phi(z_T)\)。联合方向使用 \(-(G_A+\rho I)^{-1}b_A\) 及其反向，\(\rho=\max(10^{-10},10^{-3}\operatorname{tr}(G_A)/\dim z_T)\)。单分量方向使用对应对角块，双分量组合和全分量之和使用各单分量单位坐标方向相加。组 B 重算 Fisher 并测量同一扰动。坐标轴双向、联合双向、单分量和全分量和在 2% 半径上也记录历史测试集指标。双分量组合只在训练探测图上测量。

完整记录含逐步训练、出生候选原始收益及扣罚收益、最终参数、每组 Fisher 矩阵和各个扰动的 CE、准确率、概率 KL 和 Fisher–Rao RMS 距离。Fisher 阈值秩统计大于最大特征值 1% 的特征值。组间一致性用两个 Gram 矩阵的 Frobenius 余弦。跨分量耦合用非对角分量块的 Frobenius 范数与全矩阵范数之比。结果来自单个种子，且提前接入、出生惩罚与计算上限一同改变。

## 扰动结果

两版的零扰动都复现完整专家的测试 logits。原版在两个探测组的 Fisher 阈值秩为 2、3，新版为 7、7。原版在训练末端另一组抽样图上曾报告秩 4。此次同样本协议下，新版组间 Gram 余弦从 0.969 降到 0.729，跨分量耦合从 10.1%/15.3% 升到 60.2%/61.9%。新版响应方向更多，同时响应权重对图像组更敏感，分量之间也有明显耦合。

下表的 CE 变化为扰动后减去零扰动。正数表示损失增大。均为 2% 半径下的历史 Test 结果。

| 版本和扰动 | ΔCE | 准确率 | Fisher–Rao RMS |
| --- | ---: | ---: | ---: |
| 原版零扰动 | 0 | 79.15% | 0 |
| 原版联合下降 | +0.014424 | 78.40% | 0.167578 |
| 原版联合反向 | +0.012239 | 78.56% | 0.170448 |
| 新版零扰动 | 0 | 78.83% | 0 |
| 新版联合下降 | +0.007312 | 78.51% | 0.099715 |
| 新版联合反向 | +0.002617 | 79.04% | 0.095845 |
| 新版第 2 分量下降 | −0.000654 | 79.04% | 0.106248 |
| 新版所有分量方向相加 | +0.010963 | 78.51% | 0.162731 |
| 新版第 1 坐标负向 | −0.001147 | 79.36% | 0.108185 |

新版联合下降在 0.5% 半径下使两组探测图 CE 分别降低 0.003754、0.005323，在 2% 半径下分别降低 0.013709、0.025140。2% 半径下，10 个坐标轴中有 2 个在两组探测图和 Test 上的正负方向 CE 排序都一致。没有一个轴在三组数据上同时满足一侧降低 CE、反向升高 CE。第 1 坐标负向在 Test 多判对 10 张，但两组探测图 CE 均上升。它属于扰动扫描结果，完整专家的报告分数仍为 78.83%。

新版在 0.5% 和 2% 半径下分别有 4/10 和 5/10 个双分量组合使两组探测图的 CE 都下降。联合下降和全分量直接相加在相同权重位移预算下给出了不同的概率响应和损失，表明组合方式有实际影响。当前坐标可以改变完整模型的预测，已有数据尚未验证一致的任务改善或共同融合锚点上的可用性。

## 复现

在服务器的 `~/merging/tsv` 下运行。完整专家权重、预训练轨迹和数据保留在服务器。

```bash
out=results/DTD_DYNAMICS_CONTROL_20261110
../afg_env/bin/python -u scripts/fr_hst/train_dtd_functional_dynamics.py \
  --arm adaptive_dynamics --warmup 35 --birth-penalty 0.0002 \
  --max-components 5 --output "$out"
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  ../afg_env/bin/python -u scripts/fr_hst/audit_dtd_expert_controls.py \
  --original results/DTD_FUNCTIONAL_DYNAMICS_20261110/adaptive_dynamics \
  --early "$out/adaptive_dynamics" \
  --pretrained results/DTD_DYNAMIC_TRACE_20261109/trace/step_0000.pt \
  --output "$out/controls"
```

`training.json` 对应训练输出 `results.json`，`controls.json` 对应端点评估输出。
