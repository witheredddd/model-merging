# DTD 冻结窗口的功能投影训练

本轮使用此前 A/B 相同的 DTD 3384/376 划分、预训练模型和分类头、seed 42、36 步预热与 216 步预算。留出图像只用于终点评估。使用历史 DTD Test 1880 张评价最终权重。

## 参数写回

预热结束后，AdamW 产生包含权重衰减的完整参考位移。以当前权重为锚点，在训练批次前 32 张图计算 Fisher–Rao 响应和任务梯度，联合求解所有组的坐标。Fisher 投影解和 CE 的预条件下降解各产生一条搜索方向，随后在精确曲面上用同一个参考位移范数约束搜索步长。每条方向先按拟合 CE 选步，再在该批次另最多 32 张图上选出下降的候选，零步也参与选择。

模型写入 \(s\sum_m[\phi_m(z_m+a_m)-\phi_m(z_m)]\)。权重衰减只出现在 AdamW 参考中。后 180 步的高维残差写回路径为零。逐组保存实际累计位移，并用累计和与预热后的真实权重差做闭合校验。

## 窗口几何学习

- 每 12 步尝试一次几何更新。用最近 6 个训练批次各 16 张图，在同一个当前模型上重算梯度和响应。前 4 个批次学习方向，另 2 个批次确认几何。
- 方向候选空间由当前组的联合切向量与方向拟合批次的任务梯度构成。用完整拉回 Fisher 的跨组块，在小空间内优化共享 \(Q=\operatorname{mean}_i b_i^\top K_i^\dagger b_i\)。每个已有组的切向量变化限制在原组两轴 Frobenius 范数的 15%。两个确认批次各自求联合坐标，在相同范数预算下检验精确 CE。
- 旧组先尝试适应。若前一窗口至少 3 步存在超过小代价的 CE 缺口，则从多个任务二次模型的剩余梯度中学习新的二维组。旧组与扩展组各有 16 次小空间优化步，确认时采用相同搜索预算。新组要求 \(Q\) 增加，并在两个确认批次上分别额外降低 CE 超过 0.0002。8 组为同前实验的运行上限。
- 几何只在窗口边界提交。换轴时锚点为已经写入的当前模型，重置局部坐标以使换轴的权重位移为零。保留初始组的曲率项。新组的二次项从零开始，本实现只学习两条切向轴。各组的历史累计更新单独保留。

逐步保存精确坐标写回的 CE 收益、完整 AdamW 参考的 CE 收益、Fisher 响应能量比和响应余弦。能量比衡量功能响应的量级，与 CE 和响应余弦一起解读。窗口记录每组的去组 \(Q\) 差、出生候选的独立 CE 边际、接受与否。方向学习使用有限候选空间与搜索预算，条件新增价值对应本地实证对照。

## 结果

在 RTX 4080 SUPER 上完成 216 步。留出验证 77.39%（291/376），历史 Test 75.64%（1422/1880）。相同划分的 A、B 历史 Test 分别为 81.65% 与 81.86%。本轮实现了强制投影写回，任务性能尚未达到原专家水平。

| 冻结窗口阶段 | 非零坐标步数 | Fisher 响应能量比中位数 | 实际坐标 CE 下降均值 | 同位置 AdamW 参考 CE 下降均值 |
| --- | ---: | ---: | ---: | ---: |
| 37–96 | 34/60 | 1.48% | 0.00806 | 0.11388 |
| 97–156 | 39/60 | 19.15% | 0.00928 | 0.07058 |
| 157–216 | 45/60 | 40.28% | 0.00252 | 0.01343 |
| 合计 | 118/180 | 15.10% | 0.00662 | 0.06596 |

CE 在局部候选选择图上测量。AdamW 参考在投影模型的当前参数位置试算，未写回。能量比中位数包含零步。只看非零步，能量比中位数为 34.43%，Fisher 响应余弦中位数为 0.544。全程只有 4 步的坐标 CE 下降超过当步参考。后期响应量级与参考更接近，实际 CE 收益仍有较大缺口。

15 个窗口中，7 次保持旧几何，3 次仅调整旧组，5 次接纳新组。14 次尝试出生，接受步为 49、61、85、121 和 181。两组确认批次的逐次 CE 边际和条件 \(Q\) 见 `results.json`。最终 6 组、12 个坐标，终点 Fisher 按最大特征值 1% 的阈值得到有效秩 7。

6 组累计位移的范数依次为 0.042862、0.016419、0.009973、0.007293、0.005460、0.003177。累计和相对于实际预热后权重差的闭合误差为 0.162%。日志中的 180 步非结构写回为零。实际权重、窗口末端的曲面参数和逐组累计向量保存在服务器的完整检查点。
