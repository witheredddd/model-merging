# DTD 创新残差与任务纤维诊断

在新机用原 DTD 配置从预训练点重放 216 步。Seed 42，全部 3,760 张训练图，批量 128，前 36 步热身，出生惩罚 0.0002。诊断在提交当前步更新前读取状态，实际优化、残差回流和分量出生继续使用原规则。逐窗口只保存统计量及逐图像读数。恢复点在共享内存滚动覆盖，结束后释放。

两组各 32 张探测图固定取自已经使用过的 DTD 历史 Test。它们与训练 minibatch 分离。样本用于离线解释，两组图像不参与训练决策。区间按图像进行 2,048 次配对 bootstrap，描述给定训练步上的图像变异。

令 \(v_t\) 为 AdamW 候选加回流，\(c_t\) 为实际提出的结构更新，\(r_t=v_t-c_t\)。以平方根预测映射 \(h=2\sqrt p\) 的 JVP 计算每组响应。能量是逐图像 \(\|Jd\|_2^2\) 的均值。候选响应由 \(Jv=Jc+Jr\) 得到，另记录交叉项 \(2\langle Jc,Jr\rangle\)。因此残差相对候选的 Fisher 能量可大于 1。

用截断 SVD 拟合 \(J U a\approx Jr\)，保留大于最大奇异值 1% 的方向。一组拟合，另一组评估，两个方向都做。交叉评估的新颖比例为 \(\|J(r-Ua)\|^2/\|Jr\|^2\)。出生步在同一参数点额外测量旧切空间、演化后的既有分量，以及加入新分量后的完整切空间。

有限步损失使用 \(\theta+c+\alpha r\)，\(\alpha\in\{0,0.25,0.5,1\}\)。报告 \(\mathrm{CE}(\theta+c)-\mathrm{CE}(\theta+c+\alpha r)\)，正值表示改善。另测 \(\mathrm{CE}(\theta+c+Ua)-\mathrm{CE}(\theta+c+r)\)，评价功能覆盖之外的净收益。表中方向投影使用另一图组拟合的坐标。

每组响应参考下限为等欧氏范数随机方向能量与候选能量 1% 的逐图最大值。两组残差能量相对参考下限的区间均在零下且各剂量 CE 变化与零等效时归为 V。功能响应明确、全量残差有益时，两组交叉新颖比例均不超过 0.35 归为 H1，均不低于 0.65 且超出覆盖部分的 CE 收益也明确时归为 H2。功能响应明确且有限步 CE 等效或明显有害时归为 H3。CE 等效带为 ±0.002。其余样本标记为未确定。此处类别和占比由这套操作定义限定，统计粒度为已采样的窗口。

## 结果

新机重放完成 216 步，历史 Test 为 1547/1880（82.29%），CE 为 0.729435。参考模型为 1543/1880（82.07%），CE 为 0.727829。两者都结束于 5 个分量、10 个坐标。参考出生步为 57、81、105、145，新机为 57、81、105、137。结果属于相同配置在 RTX 4080 SUPER 和 PyTorch 2.5.1 上的新轨迹。第 201 步前遇到数据盘写入异常，从第 180 步恢复点在共享内存完成剩余诊断，再校验转存。各任务原有权重均保留。

| 类别 | 窗口数 / 40 | 窗口占比 | 残差 Fisher 能量占比 |
| --- | ---: | ---: | ---: |
| V 近似竖直 | 0 | 0% | 0% |
| H1 已可表达且有益 | 0 | 0% | 0% |
| H2 新功能且有益 | 1 | 2.5% | 0.265% |
| H3 无益或有害 | 7 | 17.5% | 0.295% |
| 未确定 | 32 | 80% | 99.440% |

40 个采样窗口的残差都在两组图上超过参考下限。绝对响应随训练明显减弱，最后一步的两组能量为 \(6.44\times10^{-11}\) 和 \(4.05\times10^{-11}\)。80 个窗口与图组组合中有 75 个 Fisher 交叉项为负，残差与候选能量之比中位数为 1.19。该比值描述功能能量及抵消，无法解释为参数占比。交叉评估的旧切空间新颖比例中位数为 1.01，超出 1 的值表示拟合得到的覆盖方向在另一组上增大了误差。

全量残差在第 128、168 步有稳定 CE 收益。第 128 步超出功能覆盖部分的收益未达到 H2 阈值。第 168 步的全量残差使 CE 下降 0.01535，95% 区间为 [0.00229, 0.03251]。超出覆盖部分的收益为 0.01625，95% 区间为 [0.00367, 0.03201]。第 160 步全量残差使 CE 上升 0.02143，95% 区间为 [0.00519, 0.04370]。其余六个 H3 窗口出现在第 200 步及以后，剂量曲线落在等效带内。第 216 步实际释放全部回流，探测图上的单步 CE 效应接近零。

| 57 | 0.962 / 0.679 | 0.964 / 0.681 | 0.911 / 0.975 | 0.736 / 0.565 |
| 81 | 0.925 / 0.592 | 0.930 / 0.612 | 0.829 / 0.703 | 1.045 / 1.181 |

四次出生均未在同一参数点同时降低两组交叉新颖比例。第 57 步之后两组比例都下降，但下一步使用新的参数和残差。创新残差与负最优性残差的 Fisher 余弦中位数为 0.143，欧氏余弦为 0.087。实际出生候选方向与创新残差的 Fisher 余弦中位数为 0.292。出生机制测到的收益无法直接代表创新残差已被吸收。

这些读数来自一条轨迹和两组固定图像，且采样对出生附近的窗口加密。置信区间为逐窗口的图像层面描述，比例限于采样窗口。现有证据支持区分有益的新功能残差和无益变化。可抑制的近竖直残差，以及出生后的稳定功能吸收，仍缺少直接证据。
