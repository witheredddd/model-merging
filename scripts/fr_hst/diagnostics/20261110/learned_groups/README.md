# DTD 已学习分组的功能几何审计

终点是保存了五组完整基底的 82.07% DTD 专家。出生对照单独重放原配置，使用新机轨迹上实际出生前的参数和新生基底。训练脚本、优化器、学习率和出生规则保持原样。重放只用于取到第四次出生的状态，不产出新的专家权重。

沿用既有 DTD 3384/376 划分（seed 0）。固定从训练侧选 32 张拟合图，验证用完整 376 张。出生步依据原 DataLoader 的采样顺序排除当步 minibatch，同时在训练侧补齐 32 张。终点和重放训练本身都使用了 3760 张图，因此这里的验证独立于本次拟合和方向选择。历史 Test 不参与判据、调参或效果选择。

## 终点实验

- 在完整专家上只加相应位移。五组分别作 0.8、0.9、1、1.1、1.2 倍放缩。另一组对照按同一参数范数测正负放缩及两条组内坐标轴的双向精确非线性扰动。共同半径为各完整分量范数中位数的 10%。
- 各图组分别计算五个完整分量的 Fisher Gram 和余弦矩阵。用 10 个组对及四种符号组合计算逐图 CE 交互。单组与双组使用同一参数位置。
- 对每组移除 10% 和 100% 的完整分量，允许其余四组在移除范数以内调整原非线性坐标。拟合目标为恢复基准平方根预测嵌入，验证记录 KL、CE 和准确率。
- 固定十维切空间，对照原线性分组、三次重配对和三次旋转后重分组。每组允许一个两维更新，按组内参数度量白化，使用相同半径和 14 次真实 CE 调用。在拟合图选择一个组，再报告验证指标。重配对和旋转只用于线性对照，原非线性分组另由终点坐标扰动与补偿实验评价。

## 出生实验

每个出生点的 A 使用原有非线性组，B 在同一旧组上加入实际出生的两条坐标切向量，C 加入两条与旧切空间正交的随机单位方向，三套随机种子。新生时二次系数为零。各方案共享旧组 40 次真实 CE 评估的热启动，再分别使用 40 次真实 CE 调用，允许所有可用坐标重新调整。更新的实际参数范数上限等于该步结构更新范数。输出搜索记录及验证侧逐图配对的 CE 差区间。有限预算搜索以同样预算的局部近似最优为比较对象。

## 计算公式

设完整专家为 \(\theta_T\)，第 \(m\) 组的已拟合位移为 \(d_m\)。整组放缩在 \(\theta_T+(\lambda-1)d_m\) 上测量。组内坐标扰动的位移为 \(s[f_m(z_m+\delta z)-f_m(z_m)]\)，其中 \(s\) 为检查点保存的尺度。

对 \(N\) 张图令 \(A_m=N^{-1/2}D_\theta[2\sqrt{p_\theta}]\,d_m\)，将样本和类别维展平。Fisher Gram 为 \(G_{mn}=A_m^\top A_n\)，余弦为 \(G_{mn}/\sqrt{G_{mm}G_{nn}}\)。任意实际位移的预测二次响应与实测 \(N^{-1}\sum_i\|2\sqrt{p_i'}-2\sqrt{p_i}\|_2^2\) 比较。联合扰动的逐图交互为 \(L_i(\alpha d_m+\beta d_n)-L_i(\alpha d_m)-L_i(\beta d_n)+L_i(0)\)。出生对照的增益是验证图上配对的 \(L_i(\mathrm{control})-L_i(\mathrm{real})\)，正值表示真实新组的 CE 更低。

## 终点结果

完整专家在审计验证图上 CE 为 0.009028，准确率为 376/376。这些图已参与原专家训练。等范数扰动半径为 0.005931。下表的最大 KL 分别在两种符号的整组放缩和四种组内坐标扰动中取得。KL 恢复率为 \(1-\mathrm{KL}_{\rm restored}/\mathrm{KL}_{\rm removed}\)，相对基准均使用完整专家预测。

| 组 | 等范数整组放缩最大 KL | 等范数组内坐标最大 KL | 移除 10% 后 KL 恢复 | 完全移除后 KL 恢复 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0.000011 | 0.000025 | −82.2% | 2.9% |
| 2 | 0.000017 | 0.000921 | −46.8% | 19.3% |
| 3 | 0.000028 | 0.000220 | 8.8% | 45.7% |
| 4 | 0.000035 | 0.000262 | 6.0% | 50.6% |
| 5 | 0.000128 | 0.000160 | 41.7% | 87.9% |

50 个非零扰动的 Fisher 预测和实际平方根弦距的验证组 Spearman 相关为 0.977，30 个等范数扰动中为 0.945。第 2 组内部响应明显强于整组放缩。第 1、2 组完全移除后 CE 分别升到 1.3569、1.0920，受约束补偿后仍为 1.3208、0.8878。完全移除第 5 组使 CE 升至 0.01850，其他四组调整后为 0.01013。完全移除的剂量可以超出局部区域，因此同时保留小移除对照。

验证图上的组 1–3 与 2–4 Fisher 余弦为 −0.659 和 −0.459。32 张拟合图与 376 张验证图的十个非对角余弦 Pearson 相关为 −0.278。逐图 CE 交互经双侧配对差的 t 检验和 40 项 Holm 校正后，6 项小于 0.05。组 1、3 同减 0.1 时交互为 −0.000243，改为一减一增时为 +0.000258。局部重叠确实能测量，但图像组成明显影响矩阵，单一小探测组不足以确定稳定组关系。

在相同十维切空间下，拟合侧选择的原分组单组更新在验证侧 CE 变化接近零。原分组对三次重配对的逐图 CE 优势都在约 0.00014–0.00017，图像 bootstrap 区间都跨零。两次旋转的验证 CE 比原分组高 0.00176、0.00341，逐图配对区间均为正。第三次旋转的差异区间跨零。以上重分组区间未做多重比较校正，结果只支持原边界相对部分旋转更稳，原边界相对简单重配的优势仍未建立。

验证图上，去掉组内块后的 Fisher Gram Frobenius 范数占完整范数的比例为原分组 0.470，三次重配 0.458、0.624、0.570，三次旋转 0.846、0.613、0.768。原分组相对三次旋转的跨组响应较小，一次重配的跨组响应比原分组还小。逐组的组内谱、完整矩阵及拟合和验证指标均保存在 `endpoint.json`。

## 出生结果

下表为真实新组相对旧组重新优化后的平均验证 CE 增益。随机对照列给出真实新组分别相对三组随机对照的增益范围。区间为逐图配对 bootstrap 的 95% 区间，未做跨步、跨对照的多重比较校正，也未涵盖不同训练种子间的变异。

| 步数 | 验证图数 | 相对旧组的 CE 增益 | 95% 区间 | 相对随机新增的 CE 增益 |
| ---: | ---: | ---: | ---: | ---: |
| 57 | 359 | +0.008771 | [0.004166, 0.014784] | +0.008770 至 +0.008771 |
| 81 | 361 | +0.000794 | [−0.000985, 0.002813] | 约 +0.000983 |
| 105 | 364 | −0.000450 | [−0.002149, 0.001081] | −0.000126 至 −0.000122 |
| 137 | 366 | −0.000101 | [−0.000568, 0.000352] | 约 −0.000159 |

四次真实出生均在拟合图上优于重新优化的旧组。验证图上只有第 57 步对旧组和三套随机对照的区间都为正。第 81、105 步各方案的验证 CE 都比未扰动锚点高。第 137 步各方案都带来轻微的验证 CE 降低，真实新组的降幅小于旧组和随机对照。四次出生点和全部方案的预算、更新范数、拟合轨迹、验证统计及图像索引见 `births.json`。

终点五组具有可测的控制响应，第 2 组尤其依赖组内坐标。当前证据支持第 57 步出生在这条 DTD 轨迹及给定预算下的新增价值。它尚不足以确定五组都是必要的、原分组优于简单重配，或组关系在其他任务和融合锚点上可复用。补偿实验中完全移除所测的是较大干预，出生时的局部必要性由单独的等预算对照回答。
