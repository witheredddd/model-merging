# DTD 持续坐标与自适应功能分量

三组从同一个 CLIP ViT-B/16 预训练点开始，冻结 DTD 分类头，使用全部 3,760 张训练图。Seed 42、批量 128、216 个优化步骤。完整经过训练集七次，再执行第八轮前六步。前 75 步为相同 AdamW 预热。训练期间只记录训练损失。1,880 张历史测试图在训练和冻结表示完成后评分。

在记录有限步 CE 的训练批次上，仅用结构更新时，相对当步原始 AdamW 候选的 CE 改善保留率中位数分别为 **24.9% 和 25.3%**。两组冻结表示的参数端点相对误差分别为 **78.2% 和 76.7%**。完整自适应模型比原对照多答对三张测试图；移除额外参数更新后，准确率为 49.57%。当前结果表明分量确实增长、联合坐标确实学习，最终学到的冻结表示仍只能承担部分任务适配。

## 训练规则

对照复用原非线性载体的拟合、旋转和残差回流。三组的几何样本均取当前训练批的前 32 张，全部训练图仍用于完整批量的 AdamW 候选。两组新动力学从一个二维非线性分量开始。每个分量含两条切向轴、一条正交弯曲轴、三个二次系数和两个持续坐标。映射的共同尺度在首次激活时固定。不同分量可重叠，联合求解保留全部交叉块。

每步用同一批几何样本的 CE 梯度和 Fisher 响应计算式 (1)。以 AdamW 自适应候选范数的 60% 限制坐标切向步长，并把这个缩放计入有效坐标学习率。岭系数为 Fisher 和参数切向 Gram 迹之比的千分之一。式 (2) 的正则化残余梯度由全视觉 VJP 计算。式 (3) 使用冻结的当步坐标增量更新各分量的轴与弯曲系数。轴按各分量分别回缩。几何更新初始步长为 0.002，回退时用原步长的四分之一及十六分之一。实际几何位移在参数范数和采样 Fisher 范数上都须低于坐标切向变化的 25%。

真实结构更新使用新旧映射值之差，包含坐标与映射同时演化。预热、AdamW 补偿、权重衰减与结构更新在最终检查点上会留下合成效应。训练沿用旧版误差回流及末步清空策略。冻结诊断将最终坐标和映射直接放回预训练点，去掉全部额外高维补偿后评分。

自适应组在每八步的两个相邻训练批次考察式 (2) 的 $M$ 正交补。先计算当期几何已经调整后的结构更新，再以相同参数范数比较加入候选方向的 CE。候选需要真实降低 CE，且相对当前结构的额外改善超过 $10^{-5}$ 与当前改善幅度 2% 的较大值。两个连续训练批次通过才尝试用两条独立方向生成分量。新分量的坐标和弯曲系数为零，生成时参数连续。出生冷却 16 步。本次最多三个分量作为计算预算上限，实际分量数由训练日志记录。

## 产物和复现

完整模型与冻结表示分别计算 Test CE 和准确率。最终训练批尺度的拉回 Fisher 谱以固定种子抽取的 32 张训练图测量，按最大特征值的 1% 报告有效秩。坐标、二次系数、轴 Gram、相对端点重建误差和分量生成记录保存在 results.json。所有高维轴、参数权重和残差缓冲保存在实验服务器的 epoch08.pt。对照的最后一步坐标属于局部临时变量，因此没有对应的冻结全局重建。
