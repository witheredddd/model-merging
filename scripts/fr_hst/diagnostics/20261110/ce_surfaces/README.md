# DTD 持久二次曲面的任务学习

保留 DTD 3384/376 固定划分、seed 42、36 步 AdamW 预热和原训练入口的预训练权重与分类头。前 216 步沿用此前的学习率，之后从初始学习率的 10% 续训。留出验证连续四轮未获得至少 0.003 的 CE 改善时，将续训学习率减半，最低为初始学习率的 0.5%。

## 写回与曲面学习

- 每组保留三条高维轴、三个二次系数、两个持久坐标和一条累计实际位移。偏移以 \(b_m=d_m+A_m[-s\,\mathrm{decoder}(z_m,q_m)]\) 隐式保存。几何更新只重算偏移的低维系数，既有坐标和累计位移保持原值。
- 预热后计算当步 Fisher 预条件方向，在共同位移范数内最多执行四轮真实 CE 梯度更新。坐标拟合使用当步前 32 张图，另最多 32 张图选择是否写入。AdamW 完整参考位移提供半径和同位置对照。
- 写入时先按组累计精确二次解码的增量，然后从预热锚点和累计位移重建 FP32 权重，使用这套权重计算选择 CE。每轮验证前逐张量校验重建与实际模型一致。
- 每 12 步学习一次几何。用同一当前模型位置上最近 9 个批次，每批最多 24 张图。6 批参与曲面拟合，另 3 批确认，排除与拟合重复的图像。两轮交替优化各情境的坐标与共享曲面。曲面梯度来自各自虚拟更新后的真实 CE；更新三条轴和全部二次系数。已有轴的 Frobenius 位移上限为窗口起点的 15%，二次系数变化的 L2 上限为 0.08。
- 旧组先调轴、曲率和坐标。过去窗口内反复出现的参考 CE 缺口，结合相邻窗口在当前锚点重算的残余响应重叠，决定是否训练新曲面。残余梯度的分解只初始化三条轴。旧组和扩展组使用相同的坐标优化、曲面轮数和位移预算，扩展组必须在三个未拟合批次分别额外降低 CE 超过 0.0002。6 组是此机检查点空间的运行上限。

## 验证与停止

每轮记录训练和留出验证 CE、准确率、当前组数。216 步是可比较的观测点，20 轮也是普通观测点。至少完成 8 轮后，若验证 CE 连续 5 轮均比最佳值高出 0.003，同时最近 3 轮平均训练 CE 比最佳验证轮对应的训练 CE 低至少 0.005，则判定持续过拟合。验证 CE 决定最佳检查点，历史 Test 只在选择锁定后运行。

## 复现

```bash
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
./run-python -u scripts/fr_hst/train_dtd_surfaces.py \
  --output results/DTD_CE_SURFACES_20261110 \
  --scratch /dev/shm/dtd-ce-surfaces-20261110 --max-components 6
```

滚动与最佳完整几何状态在 scratch，验证趋势和最佳视觉权重写入数据盘。停止后尝试将校验过的完整最佳检查点复制到数据盘，再做历史 Test 与终点坐标响应评估。
