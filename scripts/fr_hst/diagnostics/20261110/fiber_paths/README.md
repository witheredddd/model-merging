# DTD 累计更新通路与受限功能纤维

按已审核的 DTD 配置重放 216 步。Seed 42、3,760 张训练图、128 张每批、36 步热身、0.0002 出生惩罚。观测器在提交更新前读取方向，账本在提交后读取实际权重。两者都不改变训练更新、残差回流或出生判断。

## 累计通路

从热身结束的参数开始，在 CPU 用 FP64 分别累计 \(A\leftarrow aA\)、\(C\leftarrow aC+c\)、\(R\leftarrow aR+(1-\tau)r\)。\(r\) 是包含回流的候选减结构更新。另记未衰减的结构和 \(\sum c\)，与最终解码器相减核验望远镜关系。重建误差分别相对实际参数变化和按坐标绝对误差报告。用固定的 1,880 张 DTD 历史 Test 评价 A、AC、AR、ACR 及实际完整专家，KL 方向为实际专家到被评估模型。CE 交互为 \(L(ACR)-L(AC)-L(AR)+L(A)\)，对应同一条已实现轨迹的端点反事实。

## 受限局部谱与有限路径

固定观测第 48、81、105、137、168、216 步的更新前参数。字典包含当时的坐标切向量、带回流候选、负最优性残差、前两次实际提交的非衰减更新，以及该步可用的出生候选。字典列先归一化，保存原列范数，再用参数 Gram \(P\) 的特征分解白化，舍弃低于最大参数特征值 \(10^{-6}\) 的方向。白化后对 Fisher Gram 求谱，保留方向及其验证组响应。报告原坐标尺度的 Fisher Gram 和 Euclidean 归一化的载体谱。小谱阈值为各图组候选空间最大 Fisher 特征值的 1%。

从历史 Test 固定抽取互不相交的 A、B 两组，每组 48 张。互换拟合组和验证组。有限直线扰动使用低谱方向、最高谱方向及受限空间随机方向，三者按实际权重位移对齐。基准半径取候选范数与 0.002 的较大值。路径从最低谱方向起步，沿固定竖直候选方向走三步，每步半个半径。拟合图组上用起始点水平 Jacobian 做截断最小二乘校正，每步最多两次，校正范数上限为累计竖直位移的一半。接受校正只依据拟合组嵌入误差。报告另一组上的 KL、Fisher–Rao 弦距和 CE，同时保留未校正直线和同一步的预测点。小谱、弱有限响应和交叉图像组稳定性需要分别检验。有限路径只在候选字典内寻找，光滑纤维和常秩性质超出此实验的验证范围。

## 水平覆盖

在拟合组的可辨识水平谱子空间中构造正则化 CE 下降方向，将其归一化后再用已有坐标的 Fisher 响应拟合。独立组记录相对未覆盖能量 \(\|J(w_H-Ua)\|^2/\|Jw_H\|^2\)，并用相同系数剂量比较原方向与覆盖方向的实际 CE。方向选择和投影均只看拟合组。CE 和 KL 的区间由组内图像配对 bootstrap 得到。跨组未覆盖能量可超过 1，表示覆盖在独立组上反而增大了误差。

在看到前四个锚点的全幅剂量结果后，追加两个末段锚点（168、216）的剂量选择对照。候选幅度为 0、1/32、1/16、1/8、1/4、1/2、1 倍基准半径，以拟合组 CE 选择，再在另一组检验。原方向和覆盖方向使用同一个选定系数，另外报告二者在验证组的逐图配对 CE 差。该补测经第 150 步恢复点接入，训练更新保持原样。

## 结果

新机完成 216 步，历史 Test 上得到 1547/1880（82.29%），与上一轮新机重放一致。出生时刻为 57、81、105、137，最终 5 个分量、10 个坐标。原参考检查点的历史 Test 准确率为 82.07%。

| 端点模型 | 准确率 | CE | KL（实际专家 → 端点） |
| --- | ---: | ---: | ---: |
| A 衰减后预热基准 | 73.67% | 0.913855 | 0.402814 |
| A+C 仅累计载体 | 54.10% | 2.128392 | 1.624493 |
| A+R 仅累计高维通路 | 50.85% | 1.875389 | 1.444630 |
| A+C+R 累计重建 | 82.29% | 0.729433 | 8.51e-10 |
| 实际训练专家 | 82.29% | 0.729435 | 0 |

累计重建参数误差为实际位移范数的 0.0494%，最大坐标绝对误差为 1.83e-5。未衰减的结构和与最终解码输出的相对误差为 5.45e-8，验证了望远镜关系。两条累计通路的参数余弦为 −0.402，CE 交互项为 −2.3605。加入载体在已有高维通路的条件下使 CE 降低 1.1460，加入高维通路在已有载体的条件下使 CE 降低 1.3990。拆账支持端点处的互相依赖，单独重建不能解释其独立任务贡献。

六个锚点互换拟合组产生 12 次谱迁移验证。最低谱候选的验证组 Fisher 能量均低于该组最大谱值的 1%，范围为 0.090%–0.523%。三步终点的校正后 KL 为 1.97e-5 到 2.77e-3，均低于同等竖直位移尺度下最高谱直线对照的 0.475%。相较未校正的低谱直线，验证组 KL 仅 6/12 次下降。与同一步预测点相比，校正使验证组 KL 下降 5/12 次。低谱方向的跨组弱响应有一致证据，当前固定 Jacobian 校正的跨组收益则不稳定，部分低谱路径的验证 CE 也出现上升。

原水平候选的跨组功能覆盖中位数为 64.6%，范围 6.8%–99.3%。第 168 步达到 95.9% 和 99.3%，但两组互换时的验证 CE 均没有确认收益。12 次全幅方向评估中，4 次验证 CE 明确恶化，0 次明确改善。末段 4 次拟合组选剂量对照的验证 CE 点估计仍全部为负收益。第 216 步在候选空间最大谱值的 1% 阈值下，10 个载体坐标对应 A、B 组的可辨识秩为 7、6。覆盖结果刻画候选的预测响应，当前测得的样本尚不能估计载体对已验证有益水平变化的覆盖率。

数据和图表基于单条 DTD 轨迹与两组固定历史图像，12 次验证含同一锚点的双向互换。在线重分配属于后续实验，当前结果只涉及同轨迹拆账和受限局部可行性。
