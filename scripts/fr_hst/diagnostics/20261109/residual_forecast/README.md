# DTD 残差的局部几何可预测性

本实验使用同一条 DTD 训练轨迹。以步 0–54 的四个窗口拟合三维基础载体，沿用残差重放的分解。随后 12 个残差窗口中，前五个用于初始化，余下七个逐窗预测。两组各 32 张训练探测图轮流负责构造状态与复核预测。图像组只针对本次诊断留出。

## 结果

下表为步 125–216 的七个时间留出窗口、两次图像组交换的合并中位数。CE 改善为正时表示损失下降。真实整窗更新在 13/14 项评分中改善 CE，保留率的分母来自这些评分。逐组结果保存在 JSON 中。

| 方法 | 整窗更新相对误差 | 残差相对误差 | 下一残差参数能量捕获 | 下一残差功能能量捕获 | CE 改善 | CE 收益保留率 |
|---|---:|---:|---:|---:|---:|---:|
| A 固定线性 | 0.945 | 0.964 | 11.1% | 23.5% | +0.0436 | +48.5% |
| B 在线局部线性 | 0.976 | 0.997 | 27.7% | 32.8% | +0.0367 | +32.0% |
| C 非线性局部映射 | 1.126 | 1.140 | 27.7% | 32.8% | −0.0464 | −97.2% |
| D 局部图册与创新 | 1.005 | 1.023 | 28.4% | 46.2% | −0.0174 | −24.6% |

载体的能量捕获用真实下一残差作事后投影，衡量载体能容纳多少响应。预测误差和 CE 使用锁定的历史预测系数。D 的响应覆盖最高，但其实际预测残差与真实响应的夹角中位数为 **96.6°**，A 为 **66.4°**。在参照维数仍为三的五个窗口中，四组功能主角余弦平方均值的中位数依次为 **0.245、0.289、0.289、0.328**。因此更好的响应覆盖和相似的函数子空间并未转化为更好的系数预测。

在每个时间窗口先对两组图像的配对 CE 差取均值。D 相比 C 在 **6/7** 个窗口改善 CE，相比 B 只在 **1/7** 个窗口改善。D 的一维创新相对其自身二维图，在 **5/7** 个窗口提高 CE 收益。最近真实残差回流后，D 的功能子空间重叠中位数为 **0.710**，对应的参数重叠为 **0.679**。回流只在 **2/6** 个时间窗口改善下一窗 CE，逐组配对改善差的中位数为 **−0.0309**。两组共 14 个预测都选中了同一个较近历史图，故此次数据支持的只是活动局部图与创新通道的对照，图与图之间的转换仍待验证。

四种载体的拟合时间中位数分别为 **0.187、0.176、0.196、0.799 毫秒**。这些是已缓存 Gram 和历史统计后的拟合开销。当前证据支持残差具有局部可组织的功能结构，同时新残差的大部分参数能量仍落在三维历史载体外。有限窗口内既观察到部分延续，也观察到明显的历史外成分。对于连续低维流形、跨阶段图册与独立创新三者的长期区分，这条轨迹只提供初步证据。结果支持将残差通道保留在后续表示中，其 EC 自由度仍需单独检验。

## 时间留出

对窗口 $k$ 的预测，拟合程序只能读取结束于起点 $\theta_k$ 的五个历史窗口。已知状态包含当前预测熵、前一窗口的单位步长 Fisher–Rao 位移，以及待预测窗口的预定步数。拟合以单位步长残差为目标，随后乘以已知宽度。各预测的前缀矩阵、状态和历史 CE 记录均单独切片。删除所有尚未发生的数据后，程序核对残差预测、载体基底和共同基础载体预测与原结果逐元素一致。forecast_plan.json 在任何虚拟更新评分前写入，结果文件记录其 SHA-256。

四组各有三个活跃残差方向，预测系数均使用相同长度的历史。共同的基础载体分量也由历史窗口外推，所有组共享它。模型评估时将共同载体预测与各组的残差预测相加。

| 组别 | 残差载体与坐标 |
|---|---|
| A 固定线性 | 用最早五个残差的单位方向拟合三维 PCA 并冻结。每窗用最近五个窗口重新拟合仿射坐标。 |
| B 在线局部线性 | 从最近五个残差重拟三维 PCA，使用相同的仿射坐标模型。 |
| C 非线性局部映射 | 沿用 B 的三维局部载体。对两个历史状态变量增加二次项和交叉项，用固定岭惩罚拟合坐标。它测量局部坐标的非线性预测能力。 |
| D 局部图册与创新通道 | 五个窗口形成两个相邻的三窗口图。根据已知状态选择其中一个活动图并拟合二维载体与二次坐标。第三维来自过去逐点预测误差在当前图外的主方向。权重使用相应历史残差单独重放的正 CE 收益作为任务效用代理。创新系数从过去外推。 |

D 的单步回流对照保持当前模型和状态变量相同，只把最近一次真实历史残差替换为当时保存的 D 预测，并屏蔽那一窗的真实残差 CE 权重。比较前后参数主角、同一参考点的功能主角和本窗真实 CE。二维图单独重放作为创新通道的额外对照。四组方向构造均使用小 Gram 矩阵，所需训练模型微分调用数为零。逐窗记录拟合墙钟时间。每组的主要评分用两次有限步前向和最多四次 JVP，B 与 C 可复用共用载体的 JVP。回流和图单独重放的开销另外计算。

## 度量

- 参数误差为 $\|\hat u_k-u_k\|/\|u_k\|$，另报残差误差与真实残差在三维载体中的参数能量捕获率。
- CE 改善用固定起点前后真实前向损失之差。真实整窗更新改善 CE 时，用它归一化预测收益，同时保留原始 CE、KL 和准确率变化。
- 功能度量使用固定当前检查点和复核图像上的 $\mathrm d(2\sqrt{p}/\sqrt n)$。预测残差和下一实际残差的响应夹角对所有窗口报告。三维功能主角比较使用本窗及之后至多两个实际残差作为事后评分参照，预测锁定后才计算。最后两个窗口参照维数下降，单列在结果中。

## 复现

forecast_plan.json 保存每窗的历史索引、状态、系数、预算和回流对照。results.json 保存逐窗、逐组的四方法评分。原始权重继续保存在实验服务器。以下命令在备有原数据和权重的仓库根目录运行。

  scripts/fr_hst/forecast_dtd_residual_geometry.py \
  --bank scripts/fr_hst/diagnostics/20261109/mechanisms/mechanism_arrays.npz \
  --replay scripts/fr_hst/diagnostics/20261109/carrier/residual_replay.json \
  --trace results/DTD_DYNAMIC_TRACE_20261109/trace \
  --queue results/EXPERTS8_99_20261109 \
  --output results/DTD_RESIDUAL_FORECAST_20261109
~~~
