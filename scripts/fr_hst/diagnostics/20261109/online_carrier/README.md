# DTD 在线载体训练结果

训练代码固定为提交 3dea8f4。两组从同一预训练点开始，各跑 8 轮、216 步。前 75 步的训练 CE 与先前已逐张量复现的 Seed 42 AdamW 完全一致。结果比较第 8 轮固定权重。历史 Test 为 1,880 张已使用的 DTD 测试图。

| 方法 | Val Acc | Val CE | 历史 Test Acc | 历史 Test CE | 实际介入步数 |
|---|---:|---:|---:|---:|---:|
| 原 AdamW | 81.38% | 0.76953 | 77.39% | 0.80359 | — |
| 在线线性载体＋回流 | 81.12% | 0.76292 | 77.50% | 0.80803 | 141/141 |
| 在线非线性载体＋回流 | 80.85% | 0.76914 | 77.93% | 0.80571 | 141/141 |

线性和非线性组相对各自当步原始 AdamW 候选的实际自适应位移变化，中位数分别为 **1.08% 和 0.98%**，最大分别为 **3.30% 和 3.28%**。两个组均有 140 步收到前一步暂缓量。11 个带回流的窗口边界上，移除回流量会改变当步载体系数。单步守恒相对误差最大低于 $2\times10^{-13}$，末步全量回写后的余量范数低于 $2.6\times10^{-7}$。

非线性弯曲项的相对范数中位数为 **0.688%**，系数从 $(0.08,0,0.08)$ 更新到约 $(0.0744,0.0031,0.0803)$。线性和非线性组的拟合图 Fisher 响应解释率中位数分别为 **62.00% 和 56.17%**。这项指标使用每组当步自身的模型与候选，分别描述两条训练轨迹。

非线性组历史 Test 比 AdamW 多分类正确 10 张图，提升 0.53 个百分点；验证准确率低 0.53 个百分点，历史 Test CE 略高。两组都低于 80% 历史测试目标。结果确认了实际更新干预、非线性项和回流，性能比较仍只有一个种子。两组共享回流，当前设计也无法单独估计回流相对于无回流训练的贡献。

summary.json 含验证和历史测试汇总。online_linear.json 与 online_nonlinear.json 含逐步记录和模型校验值。运行方法见 [ONLINE_CARRIER.md](../../../ONLINE_CARRIER.md)。权重留在实验服务器。
