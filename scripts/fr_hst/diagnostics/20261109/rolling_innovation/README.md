# DTD 滚动功能历史与 CE 门控创新

本实验比较原始 AdamW、Fisher 历史载体加 CE 门控、欧氏历史载体加相同 CE 门控。三个方案共用预训练模型、冻结分类头、DTD 训练和验证划分、增强顺序、批大小 128、AdamW 超参数和 8 轮预算。保留原始 76 轮调度曲线的前 216 步。预先固定第 8 轮作为训练结果。先完成种子 42 的三组。如果这三组正常完成且 Fisher 组实际收缩过创新，才继续种子 43、44。这个决定只用训练记录。

## 更新顺序

1. 对真实模型计算梯度并按原配置裁剪。Fused AdamW 在影子参数上更新动量和权重，生成完整候选。真实模型仍处于当前检查点。
2. 单独计算 decoupled decay 点 $\theta_t^{\mathrm{decay}}=(1-\eta_t\lambda)\theta_t$，从影子候选中减去该点得到自适应更新 $u_t$。Fisher 只分解自适应更新。AdamW 状态每步前进一次。
3. 历史由五个已完成窗口中实际接受的自适应位移组成。每 25 个全局步和每轮结束时关闭窗口。前五个窗口在第 75 步结束。在历史齐备前，三个组均接受完整 AdamW 更新。
4. 用第三组固定训练图在真实模型位置计算每条历史更新及 $u_t$ 的 logit JVP。概率加权后得到 Fisher Gram。求解 $(H^\top FH+\epsilon I)\alpha=H^\top Fu_t$，其中 $\epsilon$ 为 Gram 平均对角线的千分之一。欧氏组使用同样的历史和相对岭系数，以参数内积替代 Fisher。
5. 通过无副作用的模型前向计算 $\theta_t^{\mathrm{decay}}+H\alpha+\beta(u_t-H\alpha)$ 的 CE。对每个小于 1 的候选分别与 $\beta=1$ 做逐图配对。两组各 32 张训练图的一侧 95% 配对下界均超过 $10^{-5}$ 时通过。优先保留最多的创新，顺序为 0.875、0.75。两者均未通过时取 1。一次性写入选中的权重，并累计实际接受的自适应位移。$\beta=1$ 直接复制原始 AdamW 的影子权重。

两组门控图沿用之前的固定索引，第三组 Fisher 图与其互不重叠。三组图均来自原训练池。配对界限是训练门控规则。探测图随步骤反复使用，门控次数按描述性数据理解。

## 记录与评估

- 每轮记录验证 CE 和准确率。第 8 轮权重固定后，使用既有的 1,880 张 DTD 历史测试图评估 CE、准确率以及 80% 目标。测试图像及标签与已记录来源逐项核对。测试结果用于这次历史基准对比。
- 每步保存历史窗口索引、创新保留比例、各候选在两组图上的改善和配对下界。在窗口结束点对三组计算同一 Fisher 功能解释率。已执行解释率以接受后的自适应位移为分母。另记录实际收缩步上，相同自适应参数范数的纯标量缩放对照。该标量对照用于区分当步效应，并未形成独立的训练组。
- 验证普通 AdamW 种子 42 端点与原专家逐张量相同，并核验每个种子的三个组在前 75 步训练损失相同。Git 数据仅包含汇总、逐步日志与脚本。权重和继续训练状态位于实验服务器。
