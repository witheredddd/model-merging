# DTD 实验五 · 功能残差分解与选择性清零

本实验复用原 DTD AdamW 轨迹。保留步 0–54 的四个窗口拟合的三维基础载体，取后续窗口真实更新在其外的残差。每窗的候选空间使用最近五个已完成的历史残差。主分析覆盖步 125–216 的七个完整历史窗口。另保留四个历史不足五窗的预热诊断。第一个残差窗口没有可用历史。

## 主要结果

七个主窗口的两组交换共 14 次评分。完整更新的 CE 改善中位数为 0.0955，13/14 次为正。收益保留率只使用这 13 次，配对 CE 差使用全部 14 次。

| 创新保留比例 $\beta$ | Fisher CE 改善中位数 | 欧氏 CE 改善中位数 | Fisher 收益保留率 | 欧氏收益保留率 |
|---:|---:|---:|---:|---:|
| 0 | 0.0232 | 0.0270 | 13.7% | 40.2% |
| 0.25 | 0.0471 | 0.0756 | 57.7% | 74.9% |
| 0.50 | 0.0681 | 0.0900 | 87.3% | 94.6% |
| 0.75 | 0.0838 | 0.0965 | 97.0% | 103.1% |
| 1 | 0.0955 | 0.0955 | 100% | 100% |

- **Fisher 提高了局部功能解释率。** 拟合组和复核组的中位数分别为 **51.6%、23.5%**，欧氏在复核组为 **−6.9%**。负值表示欧氏投影后的创新在预测空间的能量超过原残差。Fisher 创新的参数能量中位数为原残差的 **1.39 倍**，说明分量在参数度量下可能相互抵消。参数缩小、局部响应缩小和有限步 CE 是不同目标。
- **直接清零创新普遍损失 CE。** 只保留基础载体及历史投影时，Fisher 在 **12/14**、欧氏在 **13/14** 次评分中低于完整更新。Fisher 和欧氏的创新分量单独降低 CE 分别为 **8/14、10/14**。保留基础载体时，两分量的 CE 交叉项中位数分别为 **+0.0539、+0.0413**，反映直接加总各自收益会漏掉联合收益。
- **部分收缩的效果随阶段而变。** 欧氏 $\beta=0.75$ 在主窗口 **11/14** 次优于完整更新，但在四个预热窗口的交换评分中有 **7/8** 次较差。Fisher $\beta=0.75$ 在主窗口 **7/14** 次优于完整更新。由此可见，单个固定保留比例的效果取决于历史支持和训练阶段。

Fisher 在本实验中能更好识别历史可解释的功能分量，但不能由此推导有限步 CE 的同向改善。单轨迹和固定训练探测图上的重放结果支持保留独立创新，并把主动收缩是否能让训练重新分配更新留作后续训练问题。

## 度量与重放

在目标窗口的起点 $\theta_t$，对每组 32 张固定训练图像计算当前预测与全视觉参数的方向 JVP。取概率嵌入 $\phi(\theta)=\operatorname{vec}(2\sqrt{p_\theta}/\sqrt n)$，令 $F_t=D\phi^\top D\phi$。这对应当前预测分布的 categorical Fisher，也等于交叉熵的 GGN。若 $R_t$ 是历史残差列矩阵，$r_t$ 是本窗已形成的真实残差，则求解

$$
\alpha=(R_t^\top F_tR_t+\epsilon I)^{-1}R_t^\top F_t r_t,\qquad
p=R_t\alpha,\qquad e=r_t-p .
$$

岭系数取历史 Gram 平均对角能量的千分之一。欧氏对照使用相同的历史列和相同的相对岭系数，以参数内积替代 Fisher 度量。两组交换拟合与复核角色。目标残差用于求投影系数，因此此处检验已形成更新的可删除性。所有指标均针对这条既定轨迹和当前探测图。

同一检查点分别重放基础载体、完整更新、投影分量单独、创新分量单独、基础载体加创新，以及基础载体加投影和 $\beta$ 倍创新。$\beta$ 固定为 0、0.25、0.5、0.75、1。保留绝对 CE、准确率、相对起点改善、相对完整更新的 CE 差及两种 KL。CE 交叉项使用完整收益减去两个载体条件的单分量收益，再加基础载体收益。重放 $\beta=1$ 的概率核对到原窗口终点。基础载体和完整更新的 CE 还与上一轮独立残差重放核对。

投影的正则化和跨组迁移会带来非零交叉项。记录参数、拟合组功能和复核组功能三个度量下的投影分量、创新分量及交叉分量能量。三项之和等于本窗残差能量。功能解释率报告为 $1-\|D\phi\,e\|^2/\|D\phi\,r_t\|^2$，保留负值。较高的局部解释率与有限步 CE 是否改善分别报告。

## 复现

results.json 保留所有窗口的历史索引、两组完整小 Gram、投影系数、求解条件数、功能分解以及全部重放评分。Git 数据包只含统计和脚本，复现需要已有 DTD 轨迹和专家权重。

~~~bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 ../afg_env/bin/python \
  scripts/fr_hst/replay_dtd_functional_residuals.py \
  --bank scripts/fr_hst/diagnostics/20261109/mechanisms/mechanism_arrays.npz \
  --replay scripts/fr_hst/diagnostics/20261109/carrier/residual_replay.json \
  --trace results/DTD_DYNAMIC_TRACE_20261109/trace \
  --queue results/EXPERTS8_99_20261109 \
  --output results/DTD_FUNCTIONAL_RESIDUALS_20261109
~~~

主动投影属于后续训练对照。它涉及 AdamW 预条件后实际参数更新和优化器状态。本实验的重放只改变单个虚拟更新，所得结果约束后续训练假设。[Online Subspace Descent](https://proceedings.neurips.cc/paper_files/paper/2024/hash/760d09bcc06b949f5ac4b6a918739aa8-Abstract-Conference.html) · [Orthogonal Gradient Descent](https://proceedings.mlr.press/v108/farajtabar20a.html) · [Gradient Projection Memory](https://arxiv.org/abs/2103.09762)
