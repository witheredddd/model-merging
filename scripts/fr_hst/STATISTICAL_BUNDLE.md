# DTD 动态概率统计流形与水平提升

本实验从 DTD 预测概率出发，每步重新计算概率底座上的任务方向。旧方向先在概率空间运输，再在当前参数点求水平提升。权重更新来自独立训练批次共同支持的方向组合。

## 概率底座与局部存在条件

在有限图像集 `X` 上，取 `q_X(θ) = concat(2 sqrt(pθ(·|x))) / sqrt(|X|)`。其环境欧氏内积给出逐样本平均的 Fisher–Rao 内积。每个类别概率为正时，`p → q` 在相应球面的正象限上是光滑坐标变换。设局部参数到 `q_X` 的映射可微且在邻域内常秩，常秩定理给出到局部像的下沉映射及其水平分解。垂直空间为 `ker J_X`，其中 `J_X = Dq_X`。用独立指定的欧氏参数度量，水平补空间为 `(ker J_X)^⊥ = im J_Xᵀ`。跨秩变化处需要重新检查正则性。实现在每步所取图像的有限统计底座上计算该分解。[Wang 与 Wang 的欧氏联络构造](https://proceedings.mlr.press/v282/wang26b.html)

## 单步算法

1. **在底座上求任务方向。** 从当前 DTD 批次取三个互斥的诱导小批。每个样本的负交叉熵自然梯度在概率坐标中为 `e_y − p`。在 `q_X` 坐标中为 `(e_y / sqrt(p_y) − sqrt(p)) / sqrt(|X|)`。
2. **求水平提升。** 对每组图像求 `u = J_Xᵀ (J_X J_Xᵀ + λI)⁻¹ v`。零阻尼极限给出最小欧氏范数的广义逆提升。实现使用 5 次矩阵自由共轭梯度迭代，核乘法由 VJP 和 JVP 实现。阻尼取目标方向 Rayleigh 商的 4%。提升在 `im J_Xᵀ`，即使求解不精确也保持所采样映射的欧氏水平性。目标对齐余弦大于 0.5 才进入候选。
3. **根据任务筛选。** 在两个互斥的选择批次上计算候选 JVP。对已有方向扣除 Fisher 投影，测试独立分量。候选需有足够的独立功能响应、两批一致的下降符号及实际有限步 CE 下降。最小余弦门槛为 0.015，独立分量范数至少为原响应的 10%，双批边际下降的一阶下界需达到已选最大值的 15%。保留秩可为 0。
4. **执行受限更新。** 在通过筛选的功能方向张成空间内按两批平均的负 CE 方向取组合，并施加 Fisher 一阶步长 0.14 和参数范数 0.18 的约束。有限步更新还需让两个选择批次的 CE 都降低，必要时减半回溯。
5. **移动底座并运输。** 在固定 8 张训练锚点上保存所选方向的预测切向量。在后一步，先沿各半径为 2 的 Fisher 球面的最短测地线做 Levi–Civita 平行运输，再用新模型的 `J_X` 重新水平提升。用这一步将概率底座的运输与参数空间的欧氏水平联络相接。共同锚点给出了可计算的经验路径。沿离散路径与直接运输的差异是路径依赖的诊断量。

## 训练与复核

从同一个 OpenAI CLIP ViT-B/16 和冻结的重建 DTD 分类头开始。每个种子用同一批次顺序训练两个完整 epoch，共 104 个逻辑步。DTD 训练划分中 3,288 张用于任务诱导和选择，训练储备中的 8 张用于概率运输，另有 16 张用于记录一步更新的 CE 变化。376 张验证图只用于每轮评估和最低 CE 模型选择。种子 42、43 各运行完整方法和 AdamW，种子 42 另运行取消运输的对照。各组数据曝光和逻辑步数匹配。

```bash
out="$PWD/results/DTD_STATISTICAL_BUNDLE"
python scripts/fr_hst/test_statistical_bundle.py
for seed in 42 43; do
    python -u scripts/fr_hst/train_statistical_bundle.py --seed "$seed" --output "$out/bundle$seed"
    python -u scripts/fr_hst/train_statistical_bundle.py --seed "$seed" --adamw --output "$out/adam$seed"
done
python -u scripts/fr_hst/train_statistical_bundle.py --seed 42 --no-transport --output "$out/no_transport42"

# 也可将 trace 指向已经按同一配置保存的种子 44 轨迹。
trace="$PWD/results/DTD_TRANSPORT_REFERENCE"
python -u scripts/fr_hst/collect_dtd_updates.py --seed 44 --output "$trace/real44"
python -u scripts/fr_hst/replay_dtd_drift.py --oracle \
    --trajectory "$trace/real44" --output "$trace/drift_diagnostic/replay44"
python -u scripts/fr_hst/audit_statistical_transport.py --experiment "$trace" --output "$out/transport_audit.json"
```

模型及数据资产见[仓库运行说明](../../RUNNING.md)。`best.pt` 和 `latest.pt` 保存 48 个矩阵的扁平参数、名称顺序和基准模型哈希。`metrics.jsonl` 记录每次提升的求解误差、方向来源、实测下降和验证结果。运输审计沿已保存的种子 44 轨迹将局部更新的 Fisher 切向量带回第一个概率状态，分别在两组共同图像上比较角度。

## 两轮 DTD 实测

| 方法 | 种子 | 最低验证 CE | 对应验证准确率 | 实际执行的几何步 | 其中采用运输方向的步 |
|---|---:|---:|---:|---:|---:|
| 动态水平提升 | 42 | 1.7563 | 52.93% | 76/104 | 32 |
| 动态水平提升 | 43 | 1.6453 | 53.99% | 79/104 | 34 |
| 动态水平提升，关闭运输 | 42 | 1.8290 | 50.27% | 49/104 | 0 |
| AdamW | 42 | 0.8131 | 77.93% |  |  |
| AdamW | 43 | 0.7275 | 80.05% |  |  |

五个最低 CE 检查点均为第 2 轮。用新进程重载后，全部验证准确率与 CE 逐项复现。在线两组的保留秩分别为 0–4 和 0–3。所有实际执行的几何步均通过两个选择批次的有限 CE 下降检查。在每轮首个实际更新上核验，已知 V/O 规范分量的欧氏能量占比低于 `4.9e-15`。

两个在线种子的平均单步选择批次 CE 降幅分别为 0.0378 和 0.0386。在另 16 张只作记录的图像上，平均降幅分别为 0.00916 和 0.00625，正收益分别出现在 46/76 和 42/79 个实际更新中。新任务提升的目标余弦中位数为 0.577 和 0.627，运输提升为 0.944 和 0.947。当前算力预算下的水平提升及小批次筛选产生了动态、可执行的更新，但独立图像的下降效果弱于选择批次，整体训练表现也低于同数据预算的 AdamW。关闭运输的对照只有一个配对种子。

历史轨迹后五组相邻比较的参数线夹角为 53.3°–62.5°。在共同概率参考点，两个图像组分别得到 83.6°–89.9° 和 73.3°–80.8°。直接运输与逐段运输的最大相对差异为 0.170。两种运输路径的差异是有限路径诊断，尚未估计参数联络的曲率张量。[结果与审计数据](STATISTICAL_BUNDLE_RESULTS.json)
