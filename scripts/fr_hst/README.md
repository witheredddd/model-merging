# DTD 局部功能更新图谱

[原在线 Fisher 投影基线](BASELINE.md)保留在 `train.py`。修订版入口为 `train_atlas.py`。它在冻结的 OpenAI CLIP ViT-B/16 和 DTD 零样本分类头上学习参数更新映射，最终把模型变化写成冻结图谱和一组可重用坐标。

## 功能等价、局部几何和更新表达

1. **功能等价。** 在每张图的中心，分别扰动一个注意力头的 V 和 O。候选生成器满足 `H² = 0` 和 `H b_V = 0`，因而可在固定 V 偏置的条件下构造补偿。两条参数轴独立进入 logits JVP。用第一批图的 Fisher 响应求近似核，再用另一批图复核。通过的方向从私有解码器输出中去除。在 48 个矩阵上另做单独扰动，搜索能在两批图上复现的弱响应组合。前一项使用了已知注意力结构来限定搜索空间，后一项检验更一般的任务近似核。
2. **更新表达。** 每张图的私有坐标同时控制 48 个视觉端矩阵。解码器包含可学习的一次项、二次项和相邻坐标交叉项。各矩阵中的方向用宽度为 4 的可训练矩阵因子存储。交叉熵通过解码器训练这些因子，也在中心附近的扰动坐标上评估。训练时从图谱解码得到实际模型权重。
3. **曲率。** 将一批预测嵌入 `2 sqrt(p)` 的 Fisher 球面乘积。由局部一阶响应构造度量，由预测二阶差分取相对切空间的法向分量。至少两个局部独立方向可用时，以 Gauss 公式估计第一个坐标平面的截面曲率。坐标步先用度量预条件，再按当前步方向上的法向加速度缩放。曲率估计使用步长 `0.04` 的中心差分，反映所选预测批次和局部图。
4. **自适应增长。** 每张图从一个私有坐标开始。新模式在一批校准图上试训练，只有在两批图上都降低交叉熵且增加独立功能响应时才加入。两批图都越出当前图的 Fisher–Rao 区域后，可开辟新图。首轮计算上限为每图 3 个私有坐标、全程 4 张图。
5. **可转换的重叠。** 新图继承上一张图离开点附近的一条二次参数曲线，作为独立共享坐标。当新图私有坐标为零，移动共享坐标 `s` 等价于将上一张图的首坐标加 `s`。训练结束时用四个非零 `s` 检查权重一致性。其他方向的局部坐标转换用 JVP 最小二乘拟合，单独记录两批图上的转换残差。
6. **稳定性检验。** 在 SGD、增维和几何校准均未使用的两组图上，分别计算冻结图的跨深度功能响应、单组移除后的 CE 变化及成对干预的交互项。不同种子的图谱分别导出，以便比较这组关系能否复现。

## 运行

脚本复用仓库里的 TSV 数据和模型接口。资产要求见[仓库运行说明](../../RUNNING.md)。DTD 原训练数据中保留 376 张做验证，其余 3384 张分为 3288 张 SGD 图和两组各 48 张的几何及审计储备。两种训练入口使用同一划分和每轮样本顺序。AdamW 对照直接更新相同的 48 个矩阵。验证集用于选择最小 CE 的检查点。

```bash
python scripts/fr_hst/test_atlas.py
python -u scripts/fr_hst/train_atlas.py --seed 42 --output results/DTD_ATLAS_42
python -u scripts/fr_hst/train_atlas.py --seed 43 --output results/DTD_ATLAS_43
python -u scripts/fr_hst/train_adamw_control.py --seed 42 --epochs 4 --output results/DTD_ADAMW_42
python -u scripts/fr_hst/train_adamw_control.py --seed 43 --epochs 4 --output results/DTD_ADAMW_43
```

图谱默认至少训练 4 轮，达到 80% 验证准确率可结束，最多训练 8 轮。`metrics.jsonl` 记录每轮验证、功能等价校验、增维决策、曲率、坐标转换误差和保留图上的耦合审计。`atlas_best.pt` 保存基准模型和分类头的哈希、分组名称、各图的映射参数、坐标和共享坐标重建元数据。`encoder.pt` 是按这套冻结坐标重建出的编码器。

## 冻结图谱接口

`compose_atlas(bundle, base, codes=None)` 接收与 `bundle['groups']` 顺序一致的基准权重张量。每组由同形状的权重矩阵堆叠而成，名称前缀 `image_encoder.` 对应分类器包装层。按记录的 `base_sha256` 载入基准后，默认坐标可恢复选定模型。传入各图的替代坐标时返回组合权重，调用方可用这些权重评估 EC 候选。私有坐标有效范围为 `[-1.5, 1.5]`，共享坐标范围为 `[-0.12, 0.12]`。当前验证范围为 DTD 单任务及其图内组合。

## DTD 复跑结果

| 种子 | 图谱训练步数 | 最低 CE 检查点 | 图谱最高验证准确率 | 图谱第 4 轮 | AdamW 第 4 轮 |
|---|---:|---|---:|---:|---:|
| 42 | 260 | 第 4 轮，77.93%，CE 0.6942 | 80.05% | 77.93% | 82.71% |
| 43 | 208 | 第 2 轮，78.99%，CE 0.7354 | 82.18% | 80.85% | 81.38% |

两个种子都生成了两张局部图。曲率使坐标步缩小至少 1% 的次数分别为 61 和 59。两次运行的共享坐标转换最大参数误差均为 `2.98e-8`，其他方向一起参与的转换在复核批次上的相对残差分别为 `1.24` 和 `0.61`。独立进程从冻结坐标重建选定编码器，两个种子的最大参数误差分别为 `9.31e-10` 和 `3.73e-9`。全零坐标恢复原始基准，替换坐标会改变生成的权重。

各图中心都复现了由注意力结构限定的 V/O 近零方向。11 次更一般的 48 矩阵搜索均没有弱模态通过两批图的复核。在两组各 16 张保留图上，两个种子的第一张图分别有 1 和 2 条深度组关系达到同号且绝对 Fisher 余弦至少 0.10 的阈值，跨两个种子和两组图共同满足条件的关系为 0 条。当前结果验证了冻结映射和共享坐标的可用性。稳定的跨种子功能耦合仍缺乏证据，两个最低 CE 检查点都低于 80% 验证目标。
