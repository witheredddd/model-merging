# DTD 在线 FR-HST

入口为服务器 `~/merging/tsv/scripts/fr_hst/train.py`。训练从 OpenAI CLIP ViT-B/16 的 `pretrained.pt` 开始，沿用服务器已重建的冻结 DTD 零样本分类头。DTD 原训练集按已有种子 0 切为 3384 张训练图与 376 张验证图。探测图和用于量历史距离的锚点均从 3384 张训练图中取样。

## 每步更新

1. 计算交叉熵梯度。将上一保留基底中的 Adam 一阶矩和二阶矩提升到原参数空间，对当前完整梯度计算 AdamW 候选更新 `d`。若候选方向的线性下降量非正，则以等范数的负梯度重新提案。
2. 将当前提案、上一轮保留的功能残差、上一轮基底及近期提案做增量正交化。以固定训练锚点上预测的 Fisher–Rao 距离筛选历史，按实际步差进行时间衰减。
3. 用轮换训练探测批次和矩阵自由 logits JVP 计算候选 Gram 矩阵 `C = Uᵀ G U`。对每个样本，将 JVP 减去预测概率加权均值，并乘以预测概率平方根。聚合所得 Gram 等于 pullback Fisher 在候选空间上的限制。
4. 对 `C` 做特征分解，用相对谱阈值识别候选空间的近似纤维方向。对功能可见模式按 `Ωᵢ = λᵢ Σₛ β^(t−s)(bᵢᵀdₛ)²` 排序。选择同时满足丢弃活动量不超过 5% 且一阶下降量保留至少 90% 的最短前缀。若无可行前缀，则拒绝本步权重更新。
5. 用相邻基底重叠矩阵做离散 Procrustes 对齐并计算主角度。设 `Q = B_newᵀ B_old`，一阶矩按 `Qm` 迁移，小型完整二阶矩按 `QSQᵀ` 迁移，再纳入当前投影梯度。以 `lr × B Bᵀ d` 更新 48 个视觉端矩阵。若投影残差仍有显著 Fisher 能量及正向下降贡献，将其优先送入下一步候选空间。

候选预算默认从 8 开始。保留秩填满预算时扩张至 16，这是首轮计算上限。谱阈值只识别有限训练探测批次和候选空间里的近似核。主角度与基底对齐描述离散相邻步的变化。

## 运行和产物

```bash
cd ~/merging/tsv
../afg_env/bin/python -u scripts/fr_hst/train.py --output "$PWD/results/DTD_FR_HST_new"
```

默认运行一个完整 epoch。使用原参数附加 `--resume` 可从 `latest.pt` 继续。`config.json` 记录输入及代码哈希。`steps/` 保存每步的谱、保留模式、坐标、主角度、下降量、残差能量和测得的预测 KL。`latest.pt` 定期保存当前权重、基底、矩和历史。`basis_epoch_*.pt` 保留每轮结束时的基底，`encoder.pt` 是结束时可加载的 ViT-B/16 编码器权重。步骤坐标乘以学习率后才是实际更新的坐标，且只与当步基底配对。

## DTD 首轮复核

结果保存在 `results/DTD_FR_HST_verified_20261109`。种子 42 完成一个 epoch，53 次提案全部通过约束并用于更新。376 张验证图上的准确率从 43.62% 升到 75.27%，交叉熵从 2.0809 降到 0.9042。

保留秩在 1 到 9 之间变化，候选秩最高为 11，38 步发生截断。最低下降量保留比例为 90.24%，最高历史活动量丢弃比例为 4.93%。一次残差触发功能创新。首步 JVP/VJP 伴随校验相对误差为 `7.91e-7`，末步基底 Gram 的最大误差为 `8.07e-8`。最终编码器与恢复检查点中的 48 个训练矩阵逐元素一致。

本轮所有候选 Fisher 特征值均高于近似核阈值，实际截断来自功能活动量筛选。结果只覆盖单种子一轮的训练可行性，方法相对普通 AdamW 的收益需要配对实验才能估计。
