# DTD 任务更新的 V/O 商空间实验

实验分开检验三个问题。注意力规范自由度能否在所有头上消除。剩余的任务更新能否用少量坐标在独立种子上复现。两个独立区域能否在多维邻域中互相转换。先前的[曲线连接局部图](README.md)保留为单独实验。

## 规范纤维与水平提升

每个头对 V 权重和偏置应用 `S`，同时对 O 的对应列应用 `S⁻¹`。12 层、每层 12 头的变换可以独立组合。实验逐头验证随机有限变换，并对全部头的联合变换使用同一批图片。只改变 V 的干预用于检测检验是否有灵敏度。只要 O 的对应列满秩，`H ↦ (HV, Hb, −OH)` 在该头上就是单射。

训练参数限于 48 个矩阵，因此实际用于学习的水平投影固定 V 偏置，约束为 `H b = 0`。令 `Q` 张成 `b` 的正交补并写作 `H = K Qᵀ`。欧氏最小二乘投影的正规方程为 `OᵀO K + K QᵀVVᵀQ = (ΔV Vᵀ − OᵀΔO)Q`。对左右两个小矩阵特征分解后逐元素求解。对每个头从更新中减去拟合的规范切向量。不同头在 V 行和 O 列中的支撑互斥，因此这 144 个投影可以独立求解。

## 独立轨迹、同秩对照与有限干预

- 在同一 DTD 训练划分上，用真实标签训练种子 42、43、44，用固定的样本级标签打乱训练种子 42、43 的对照。每 8 步采集一次实际 AdamW 参数位移。打乱保留类别数量。两种条件共享图像、增强和批次顺序。
- 用 42 和 43 的局部窗口以及一组训练保留图估计 Fisher 响应的典型相关方向。候选须在另一组图上通过相同的 0.70 余弦门槛。种子 44 的参数轨迹及第三组图用于计算样本外解释能量。系数只在第一组图上拟合。负值表示预测残差比全零响应更大。
- 冻结字典后，从预训练模型只训练坐标。比较商空间 Fisher 相关方向、原参数中的 Fisher 相关方向、商空间参数 PCA 及打乱标签字典。各组使用同秩、同坐标优化器和同一 DTD 训练顺序。
- 对同一任务方向拆开 12 层并测量每层的 Fisher 响应。通过两批图和种子 44 的边才进入候选。选择复核幅度最强的一条边，在两组从未用于这些测量的图上分别移除两个层的学得位移，并计算联合 CE 干预的交互项。
- 第一轮与第二轮分别建图。在第一组图上拟合三维坐标转换和反向转换，再到独立图片上测量预测误差与往返误差。若有不足三维的可复核方向，三维转换按探索性诊断解释。

`continue_dtd_task.py` 另外检验一个任务监督的修正方向。它从已冻结的一维模型出发，在两批独立的有标签图上分别拟合 Fisher 球面上的交叉熵下降向量。对照共用同一个商空间候选库，分别打乱监督标签或取消 Fisher 预条件。第三批图用于检验固定幅度下的 CE 变化，然后用完全相同的方式只训练新增坐标。

## 复现

使用[现有模型与数据资产](../../RUNNING.md)，在 TSV 根目录运行。轨迹保存完整的位移张量，五组轨迹共需约 24 GB 磁盘。

```bash
out="$PWD/results/DTD_QUOTIENT"
mkdir -p "$out"
python scripts/fr_hst/test_quotient.py
for seed in 42 43 44; do
    python -u scripts/fr_hst/collect_dtd_updates.py --seed "$seed" --output "$out/real$seed"
done
for seed in 42 43; do
    python -u scripts/fr_hst/collect_dtd_updates.py --shuffled --seed "$seed" --output "$out/sham$seed"
done
python -u scripts/fr_hst/study_dtd_quotient.py --trajectories "$out" --output "$out/study" --epochs 3
python -u scripts/fr_hst/audit_dtd_quotient.py --study "$out/study"
python -u scripts/fr_hst/continue_dtd_task.py --study "$out/study" --trajectories "$out" --output "$out/continuation"
python -u scripts/fr_hst/lock_dtd_task.py --run "$out/continuation" --output "$out/selected" --test
```

日志及校验信息位于各结果目录。`decoder.pt`、`continuation.pt` 和锁定的 `selected.pt` 包含基准权重哈希、矩阵顺序、方向及坐标。按 `θ = θ₀ + a @ B` 恢复权重。

## 实测结果

### 已知规范自由度

144 个头逐头变换的最大 logit 偏差为 `1.14e-5`，全部头同时变换为 `1.34e-5`。第二个参数位置的联合变换偏差为 `1.14e-5`。只变 V 的偏差分别为 `0.678` 和 `0.289`。理论 GL 轨道的维数是 589,824，固定非零偏置后实验投影的维数是 580,608。实测轨迹窗口仅有 0.15%–0.24% 的欧氏更新能量落在这一规范族内，水平投影前后的预测 JVP 相对差异小于 `5.4e-7`。

### 标签依赖与局部耦合

初始区域的数据筛出一个可复核方向。其跨校准图 Fisher 响应余弦为 0.946，打乱标签对照为 0.866，因而高余弦本身也可以出现在打乱标签轨迹。把种子 44 的更新系数在拟合图上估计后，在独立图上解释的能量分别为商空间 17.66%、原空间 17.66%、参数 PCA 17.67%、打乱标签 9.37%。冻结字典、从原始模型用真实 DTD 数据训练三轮后，四组分别达到 76.86%、76.86%、75.80%、44.15%。这些对照支持初始方向的任务标签依赖，也显示去规范化本身对这个实验的预测结果影响很小。

初始区域按预设阈值在两个种子来源与两组图上复现了 44/66 条层间响应关系。选出的最强边为索引 8 和 9 的 Transformer Block，两层同时移除的 CE 上升比各自独立移除之和分别多 `0.0514` 和 `0.0441`。两批各 24 张新保留图上的配对 bootstrap 95% 区间分别为 `[0.0281, 0.0815]` 和 `[0.0206, 0.0745]`。这是对这条边在当前冻结更新中的有限干预证据。

### 任务监督修正与第二个区域

| 新坐标的拟合方法 | 最低验证 CE | 对应准确率 |
|---|---:|---:|
| 真实标签，Fisher 预条件 | 0.7028 | 81.12% |
| 打乱标签，Fisher 预条件 | 0.7650 | 77.66% |
| 真实标签，欧氏方向 | 0.7440 | 77.93% |

真实标签修正把原冻结一维模型的验证准确率从 76.86% 提升到 81.12%。对这个两坐标模型，先按最低验证 CE 锁定第 1 轮，再评估 1,880 张 DTD 测试图，准确率为 77.93%，CE 为 0.7666。该测试划分在历史实验中使用过。本次固定幅度修正在校准和拟合图上降低 CE，在第三组图上平均增大 CE 0.0844，因而仅靠局部监督拟合的校验仍不足以保证泛化。

第二个区域的商空间一维方向在独立种子和图上的解释能量为 −37.19%，比全零预测更差。三维转换在拟合图上满秩，但独立图的相对误差为 0.88–2.11，最大坐标往返误差为 0.97。可复现证据集中在初始区域的任务更新方向、一条层间关系和冻结两坐标模型。两个区域的共同低维图谱仍未成立。
