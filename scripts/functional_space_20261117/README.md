# 条件功能空间辨识：真实训练位置作载体

本流程取代把CE下降作为模式接受条件的实验。研究对象始终是**目标功能需求及保护约束诱导的条件参数运动、驱动—补偿关系和跨位置可复用模式**。

实际普通学习产生的参数轨迹只提供参数位置和已有运动参考，不作为唯一的空间学习目标。算法不做训练轨迹PCA，不把训练轨迹增量直接改名为功能组，不生成无任务意义的随机扰动，也不再优化或改写该训练轨迹。

## 三个对象

1. **载体位置**：记录的普通训练参数theta_i，逐文件哈希验证；重放末端还须与原普通训练专家逐张量相等。派生扁平缓存也与原参数逐位核对，禁止静默替换、插值或虚构未记录的步。
2. **条件运动**：在theta_i按任务功能需求b_T及七任务保护代价，解完整参数空间联合WLS。参考需求包括实际普通学习运动的当前任务响应，以及既有专家运动的任务响应。它们提供b_T，最终运动仍由保护条件构造，而非原样回放参考向量。等式条件原语保留在R3数学模块。
3. **功能模式**：从完整条件运动展开驱动支持，补偿端包含全部其余参数；计算保护诱导T作用，形成图内选择性谱与联合模式。参考误差和补偿误差进入连续可信度，机器秩和模式数不是成功指标。

## 如何评估

- 完整条件运动在已构造模式中的参数重构误差。
- 对各任务的条件功能响应重构误差、指定目标响应误差及保护响应能量。
- 固定驱动时补偿降低的保护代价、抵消关系及原始算子残差。
- 到另一个**真实训练参数位置**，用相同新Jacobian、相同新需求和保护权重比较冻结旧模式与重建补偿模式；对T作用变化给出误差界解释。
- 反事实的theta_i+Bz可以用于测量有限功能变化，但不写回载体。CE与Top1只读记录，不决定是否学习模式或是否推进到下一个真实位置。

本阶段不要求准确率变化，不用CE下降做接受条件，不要求重新训练基础模型或专家，也不将验证准确率作为空间的出生门槛。

## 运行

```bash
python -m unittest discover -v
python space_worker.py --source OLD_PAUSED_EIGHT_TASK_PROTOCOL \
  --trace ACTUAL_NORMAL_TRAINING_TRACE_DIRECTORY \
  --coordinates ORIGINAL_PARAMETER_ORDER_JSON \
  --output INDEPENDENT_SPACE_OUTPUT --work-quantum 4 --gamma 0.1
```

依赖相邻 `functional_control_r3_20261117` 的已验证WLS、补偿、谱、事务和缓存原语，以及原完整空间JVP/VJP运行环境。启动前核验旧优化服务完全退出；本流程使用独立输出目录，不继续旧的CE优化模型位置。

载体由原记录用尽后正常结束；这是输入采样范围，不是结构维数上限。目标任务和参考需求族按带年龄/成本/误差/信息的队列轮换；在有限载体采样内实际覆盖多少条件要报告，不能声称穷尽所有条件。固定gamma和I度量是本阶段设置。

## 来源与边界

原普通训练轨迹、探针与模型资源留在A100，不随源码上传。生产入口要求普通AdamW完整视觉训练的来源、原专家哈希、末端逐张量一致性和记录参数的哈希校验。轨迹只包含真实保存的位置，不声称拥有每一个优化步的完整参数。

低维性、支持关系、跨位置复用及后续EC收益都需要实测；一次参数投影或学习窗口残差下降不足以证明研究成功。这里不恢复历史训练、不新增CE训练写回，已有R3受控优化入口仅作为历史独立模块保留。
