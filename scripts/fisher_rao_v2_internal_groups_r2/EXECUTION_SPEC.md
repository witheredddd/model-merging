 Fisher–Rao v2：单任务内部功能分组与低维提升学习——修订执行规格

日期：2026-11-11。依据原 `fisher_rao_execution_spec.md` 改写。本文件是**替代方案**，不是已实施或已验证的算法；保留现有 v1 的历史结果与版本哈希。

## 0. 修订决定（与 v1 的根本区别）

| 对象 | v1 | v2 冻结目标 |
|---|---|---|
| 分簇对象 | 不同来源任务/专家 | **同一个任务内的多个候选更新所产生的 FR 功能响应** |
| 观测映射 | 跨任务联合探测为分簇提供基础 | 单任务固定预测映射 `Phi_{k,X}`，每任务独立商空间；联合映射仅用于后续融合验证 |
| 初始化时点 | 完整专家/多个终点提供任务间分簇 | 少量预热后，固定同一局部锚点，用多批次/时间窗候选更新建立内部初始组 |
| 低维表示 | 每任务一组 `U,a` | 每任务若干组 `U_{k,m},z_{k,m}`，共享固定局部提升算子，合成高维模型 |
| 学习对象 | 单组线性字典内水平提升 | 任务损失联合优化多个可调低维功能组及坐标；所有实际权重从低维表示生成 |
| 纤维 | 水平模型后再学习近核候选 | **可选的独立机制阶段**；不将“分组”与“纤维”混为一谈 |
| 跨任务聚类/融合 | 先分任务簇，再簇内及跨簇平均 | 八个任务**分别完成内部学习**，再分析组间共享、特异与损失冲突，之后再做 EC |

**核心科学假设：** 某个任务在短暂预热后，多个更新候选的预测响应可由少数可复核的局部功能子结构组织；从这些结构出发联合优化低维映射与坐标，可以生成接近高维专家质量的参数更新。不预设必须多组或固定组数，不把相似度簇直接宣称为独立功能模块。

## 1. 数据、模型、种子及旧实验兼容

- 主模型为相同 CLIP ViT-B/16 基座、48 个视觉权重矩阵，其他参数冻结；各任务各自拥有固定头和数据划分。不得把“只训练最后两个块”的算子核验配置混作主实验。
- 首先仅以 DTD 进行 v2 机制核验，再扩展 SUN397、Cars、EuroSAT、GTSRB、MNIST、RESISC45、SVHN。八任务可以顺次执行但不能先按任务聚类生成内部组。
- 数据保留 `X`（构造 FR 响应/学习几何）、`X'`（独立复核结构）、`Y_basis`（独立梯度构造/归因）、`Y_fit`（必要时纤维训练）、`V_cap`（预热是否有任务收益）、`V_cal`（所有超参和停机/组数选择）、`Z`（仅一次锁定测试）。各集合彼此不重叠，专家与映射训练不可读取保留验证和测试图像。原镜像 DTD 3760 训练池、保留 1536、余 2224 的事实如实记录，不声称官方折号已核对。
- 保存 v1 的完整专家检查点作为参考上界与诊断材料；**v2 的组初始化不得读取同任务未来 4000 步端点**。在 v2 使用早期数据的预算与参考专家的训练预算之间给出公平对照。
- 预热候选窗口 `t_w ∈ {50,100,200}` 是需要在开发集比较的**方案值**，不是已经证实的最优点；先做 DTD 原型，优先 100 步。种子 11、23 用于开发，37、53 作独立复核。

## 2. 单任务经验功能商空间：定义保留，索引和用途重写

给定任务 `k`、固定头、固定观测集合 `X_k` 以及活动参数空间 `Theta`，定义

\[
 p_{k,\theta}(x)=\operatorname{softmax}(z_{k,\theta}(x)),\quad
 \Phi_{k,X_k}(\theta)=\bigoplus_{x\in X_k}2\sqrt{p_{k,\theta}(x)/|X_k|}.
\]

平方根坐标的每个样本位于正象限半径 `2/sqrt(|X_k|)` 的球面，乘积球面的欧氏诱导度量对应经验 Fisher–Rao 度量。Log/Exp、近零角和 FP64 累积，沿用 v1 第 0.3 节数值规则。

**经验等价关系及商空间：**

\[
 \theta\sim_{k,X_k}\theta'\iff \Phi_{k,X_k}(\theta)=\Phi_{k,X_k}(\theta'),\quad
 \mathcal Q_{k,X_k}=\Theta/\!\sim_{k,X_k},\quad
 \mathcal F_{k,q}=\Phi_{k,X_k}^{-1}(q).
\]

在局部锚点 `theta_w`，记 `q_w = Phi_{k,X}(theta_w)`、`J_{k,w}=D_theta Phi_{k,X}(theta_w)`，定义

\[
 F_{k,w}=J_{k,w}^{\top}J_{k,w},\quad
 \mathcal V_{k,w}=\ker J_{k,w},\quad
 \mathcal H_{k,w}=\operatorname{Im}J_{k,w}^{\top}.
\]

- 局部**底空间**是经验可达预测像中的一个待学习低维图；它不是自动等于全部商空间。
- **功能组**是此局部可达切空间内的一组候选子空间 `U_{k,m}`。同一任务可同时利用多组；组之间可重叠。**组不等于纤维，亦不等于一个独立的商空间。**
- 精确纤维 `F_{k,q}` 在固定映射下已经定义，不由聚类“出生”。纤维方向是经验观测上保持预测的一阶核方向，且随锚点变化。数值近核不得宣称全局功能不变。
- 常秩正则邻域内的局部商/纤维结构遵循原 v1 的常秩定理讨论；不宣称整个神经网络参数空间是全局光滑纤维丛。使用不同观测 `X'` 的映射和核一般不同。
- 多任务联合映射 `Phi_joint=(Phi_{1,X_1},...,Phi_{8,X_8})` **仅在后续融合分析时定义**；其核为各单任务核的交集，不能替代单任务内部组的发现。

## 3. 少量预热后，获取同任务内部候选方向

### 3.1 锚点和候选的可比性

1. 从共同基座 `theta_0` 用本任务短暂 AdamW 预热至 `theta_w`，冻结检查点。必须把 `theta_w-theta_0` 作为**固定预热偏移**完整计入最终模型，不能一边以 `theta_0` 为参数锚点，一边用 `J(theta_w)` 的提升算子却忽略这段偏移。
2. **在同一个 `theta_w` 上**，从不同 minibatch / 类别平衡切片计算多条梯度或 AdamW 预条件候选方向 `v_j`；可另外分析预热轨迹的窗口位移，但不可把不同锚点的 `J(theta_t)v_t` 当作同一切空间向量直接求余弦。若对历史窗口统一比较，应将这些 `v_j` 作为扰动输入，统一在 `theta_w` 重新计算响应。
3. 候选来源建议：至少 4 个相互独立训练 minibatch，跨多个时间窗和样本切片；记录 `v_j` 的参数范数、任务损失方向导数、随机种子与来源标签。实际候选数量按开发预实验锁定，绝不由测试集决定。
4. 以共同锚点计算 `r_j=J_{k,w}v_j`，并以有限小步检查 `Log_{q_w}(Phi(theta_w+epsilon v_j))` 是否与 `epsilon r_j` 一致。小响应方向基于测得前向噪声剔除，不能将接近零的长度归一化为单位向量。

### 3.2 功能响应相似度与“组”的判定

对有效候选计算

\[
 c_{jl}=\frac{\langle r_j,r_l\rangle}{\|r_j\|\|r_l\|},\quad
 D_{jl}=1-|c_{jl}|.
\]

`|c|` 仅用于把同一无向功能轴的正负候选合并（因为优化方向的符号可由后续坐标表示）；同时保留**带符号**的 `c` 和任务损失方向导数，避免把相反的有益/有害更新当作效果相同。可用凝聚层次聚类作初始化，不能把聚类结果当作已识别的独立模块。

- 候选组数 `M` 由开发集上的跨 minibatch/种子稳定性、可达维数、合并/删除检验决定；允许 `M=1`，不强制分出 2–4 组。
- 每组至少有足够相互独立的候选支撑；复核 `X'` 上组内/组间相似度、候选方向的 CE 导数和功能响应重复性；拒绝纯噪声组。
- 检查 **两个组是否只是在同一子空间里的不同基底**：报告主角度、响应 Gram、相互条件投影能量；接近等价则合并。`M` 不可仅根据图像聚类的可视化决定。
- 原 v1 中 `S_all`、`S_cross`、任务间 ARI、每簇必须两个来源任务及 500 次跨任务 bootstrap **从单任务初始化中全部删除**。可以做**单任务候选重采样稳定性**，有必要才引入 bootstrap；与跨任务簇完全不同。

## 4. 多组低维初始化、字典可达性和真实提升

### 4.1 初始化字典和多组

从 **同一任务早期候选方向和早期窗口**（不使用后期专家）构造正交字典 `S_k in R^{Dxd}`，首轮 `d<=16`，覆盖不足时按预设规则试一次 `d<=32`；梯度字典和轨迹字典分别作等秩对照。计算

\[
 A_{k,w}=J_{k,w}S_k,\quad C_{k,w}=(A_{k,w}^{\top}A_{k,w}+\lambda I)^{-1}A_{k,w}^{\top}.
\]

用 `A_{k,w}` 的稳定奇异值和噪声阈值确定字典内可达响应像 `Im(A)`, 以及 `P_A`。对第 `m` 组的有效响应矩阵 `[r_j]_{j in G_m}` 先投影 `P_A` 再做局部 SVD，得到 `U_{k,m}^{(0)}`，各组维数 `r_{k,m}` 由同一开发预算与谱稳定性决定。各 `U_m` 在功能响应空间正交化**只在组内进行**；跨组允许真实重叠但必须记录并检验。若某组响应的可达保留率不足，记为初始化失败/补充字典检验，不可硬解码。

### 4.2 首版多组提升模型

给定 `z=(z_1,...,z_M)`、第 `m` 组的响应基 `U_m`，定义

\[
 u(z)=\sum_{m=1}^{M} U_m z_m,\quad
 x(z)=C_{k,w}u(z),\quad
 \boxed{\theta_k(z,\{U_m\})=\theta_w+S_kx(z)}.
\]

`U_m` 是学习的功能切向组，`z_m` 是其低维坐标。统一右端线性叠加后只需解一次阻尼最小二乘。对真实模型计算 `Phi_{k,X}(theta_k)` 和训练损失 `L_k(theta_k)`。该模型是**关于固定 U 时 z 的线性参数提升**，但预测像可非线性；`C,S` 首轮固定，不是全局逆映射，也不会产生 `span(S)` 之外的高维新方向。

`K=1,B=0` 保留。此时 `Exp_q(Log_q(...))` 可作为数值目标/对照，但 Log 与 Exp 在锚点局部相消，不应把这个组合宣传为额外学到的曲率机制。

### 4.3 任务损失反向和多组共同学习

对于单任务真实参数梯度 `g_theta=grad_theta L_k`，有

\[
 g_x=S_k^{\top}g_\theta,\quad
 h=A_{k,w}(A_{k,w}^{\top}A_{k,w}+\lambda I)^{-1}g_x,
\]

\[
 \nabla_{z_m}L_k=U_m^{\top}h,\qquad
 \nabla_{U_m}L_k=h z_m^{\top}.
\]

每组 `U_m` 按其自身 Stiefel 切空间投影、QR 回缩，`z_m` 常规梯度更新；更新后实际模型**重新由完整多组解码**。从 `z=0` 起步时 `grad_U=0`，因此先更新 `z` 再更新 `U`，或用有依据的小幅非零初始化；这是代码断言项。控制各组响应方向的渐进旋转/局部重叠、参数位移预算和真实 CE 回溯，但不能用硬正交强迫本来相关的功能组分离。初步可试一个**弱结构保持**目标（在开发集选择权重，并对零正则做消融）：

\[
 \mathcal L_{\rm train}=L_k(\theta(z,U))
 +\mu\sum_m\|U_mU_m^\top-U_m^{(0)}U_m^{(0)\top}\|_F^2
 +\nu\sum_{m<n}\|U_m^\top U_n\|_F^2.
\]

第一项负责真实任务收益，第二项阻止组在每一步完全无约束地重命名/旋转到任意方向，第三项只作为可选择的防完全塌缩项，**不是宣称不同真实功能必须正交**。对于允许真实重叠的任务，`nu=0` 也必须作为对照；若强制分离损害性能，应删除该约束。

**识别性警告：** 如果所有 `U_m,z_m` 均任意旋转且只评估最终合成 `sum_m U_m z_m`，它可能等价于单个大空间，所谓多个组没有独立意义。为证明组的必要性，至少报告：独立种子下的功能响应特征是否稳定、组删除后（允许其余组同预算重新优化）的性能差异、合并为同总秩单组的对照、跨组交互项及训练全过程每组更新响应轨迹。仅报告最终模型准确率不足以证明“分组成功”。

## 5. 纤维学习：作为独立、可选的近核机制，不承担组初始化

在已学到水平模型 `theta_h` 后，固定该任务 `Phi_{k,X}`、`q_h`，并在 `theta_h` 重算 `J_h`。在固定观测意义下定义纤维/水平空间。以 `J_h v≈0` 的方向作为**候选纤维方向**，可由独立任务梯度/候选字典构造，不能默认 `ker(J_h S_k)` 含有任何非零方向。

- 若 `J_h S_k` 满稳定列秩，字典内近核为空；该结果合法。可用 v1 规定的矩阵自由 JVP/VJP 正则化求解在更大活动空间提取候选，并记录真实性能与运算代价。失败应明确记为“近核未证实”。
- 以 `delta_theta_v=N b` 作为附加位移，通过固定局部水平修正算子尽量恢复 `X` 上 `Phi` 不变；各真实中间模型都做前向 FR 漂移核验。原 v1 的最多四步有限修正、保留率和位移半径规则可保留为开发配置。
- 必须同时在 `X'` 检查预测保持，并报告 `Y_fit` / `V_cal` 的任务 CE 是否改善；仅在构造 `X` 上不可见不等于对整个任务无影响。随机核、固定方向、无约束四臂保留，主比较匹配参数位移与开发集收益。
- 本阶段学习的是**沿既有经验纤维附近的有效参数代表选择/偏移**，不是重新定义商空间，也不是第 3 节的功能分组。若主目标只是验证多组低维提升，第 5 节可以等待水平映射结果，不应阻碍主训练。

## 6. 单任务验收：把“多组”与“低秩整体”真正区分开

### 必须报告（开发和独立复核）

1. 初期功能响应的有效维数、组数、各组样本数、FR 组内/组间相似度与 `X'` 复核。
2. 单组 `M=1` 与多组 `M>1` **同总坐标秩、同 S 字典、同训练前向预算** 的真实 CE、Accuracy、FR 终点重建误差；可加 `U` 固定和随机组对照。
3. 组删除、合并及补偿式重新优化后的性能变化与跨组耦合；不能只看删除后未优化的损失差。
4. 从早期组初始化到训练结束的 `U_m` 主角度漂移、`J_t` 中真实响应、每组实际参数更新范数和独立验证上的预测收益。
5. 与全量活动参数 AdamW 专家和此前结构训练基线比较。DTD 的高性能历史结果作为性能参照，保持同一数据/参数/评估协议或注明不可比。
6. 可达性和拟合失败时明确区分：早期候选不足、`S` 覆盖不足、提升阻尼损失、组数/组内秩不足、训练优化不足；不自动把所有失败归因于“需要新组”。

### 冻结对照

`A`：无分组、同总秩单一 `U,z`；`B`：FR 内部分组，多组训练；`C`：随机分组，同组数/总秩；`D`：参数欧氏余弦分组，同预算；`E`：动态出生（可作为后续历史算法对照，不是 v2 必需条件）；`F`：固定初始 `U_m`、只学坐标。至少 `A–D` 完成之后才能声称 FR 内部分组有独立价值。

组数和其他超参数只用开发数据决定；所有正式测试仅在规则锁定后执行，不能以 Test 是否好看决定下一阶段是否启动。

## 7. 八任务完成之后，再做任务间几何与 EC

每任务独立得到 `({U_{k,m},z_{k,m}},theta_k)` 后，再在**共同锚点/兼容头/联合探测定义**下比较不同任务的功能响应，考察共享、特异及冲突。一个任务允许对应多个跨任务关系；不能硬性要求任务只能属于一个簇。FR 相似度反映预测变化方向；是否协同改善或冲突，必须用各任务损失梯度和真实合并实验检验。

最终 EC 搜索变量为经过必要性验证的低维组权重、组坐标或其结构化组合，而不是 v1 固定 `w_c=1/C` 的簇平均和单个全局 `alpha`。共同基座上的参数组合应保持原始权重一致且考虑任务间组的重叠与交互。阶段 1 不用官方测试集触发融合阶段。

| 第 5 节 | **暂停并以后重写** | 删除“先任务分簇→簇内/跨簇平均”的主算法；改为后续组级 EC |
| 第 6 节 | **保留为诊断** | 等 FR 剂量归因可保留，但不能代替组必要性验证 |
| 第 7 节 | **修订输出** | 新增候选来源、组数、响应矩阵、组重叠、组删除/合并、早期至终点漂移 |

## 9. 实施次序与旧后台作业处理

**不在旧 v1 代码/结果目录上直接修改和恢复。** 另建 `fisher_rao_v2_internal_groups` 与独立结果目录，锁定新 manifest/hash。v1 已运行的专家检查点、数值测试和日志保留为对照，但不能把完整终点反向用于 v2 预热分组。当前服务是否运行需在服务器上实时检查，不能凭上次部署记录推断。

建议先运行：

1. **DTD 预热 100 步原型**：在统一 `theta_w` 构造多批次候选 `v_j`，输出 `r_j`、谱、聚类稳定性、`X'` 复核，看看是否确实存在不止一个可解释的功能组。
2. **DTD 同预算 A/B/C/D 训练**：`M=1`、FR 多组、随机多组、参数余弦多组。检验真实性能、组删除/合并，以及 `U_m` 是否持续演化。
3. **仅在多组有可复现增益且结构必要性通过后**再启动第 5 节纤维效果研究和八任务迁移。若首轮只能得到单组，应如实报告：方法的单任务多组假设尚未成立，不可为了“分组成功”强行加组。

### 一项必须明确的解释边界

`theta_w + S C sum_m U_m z_m` 是固定有限维字典中的可训练**局部提升**，不是无限表达能力的真正全空间反函数；自由旋转的多个组也不会自动对应独立的功能自由度。对算法的最强主张应由组稳定性、同秩对照、组删除/合并及性能共同支持，而不是仅依赖低维坐标数目或几何命名。
