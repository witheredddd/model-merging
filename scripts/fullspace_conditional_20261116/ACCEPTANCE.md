# 完整参数条件求解：当前验收范围

阶段A已关闭，不追加旧模式全面审计。本阶段只验收完整参数条件求解，不开展结构学习或EC。

## 冻结数学问题

`g_T = grad CE_T(theta)`，`u_T=-g_T/||g_T||`，`y_T=J_T u_T`。g_T精确为零则记录方向未定义，不生成随机优化方向。

求解 `min 0.5||J_P v||² + 0.5 lambda ||v||²`，约束 `J_T v=y_T`。参数变量覆盖全部86,192,640个共同视觉参数，无专家字典、支持名单或模式数约束。

`lambda=gamma*s_P`，s_P是完整域Fisher幂迭代的谱尺度估计，不称精确谱范数。当前gamma诊断样点为0.01、0.1、1，不按结果宣布唯一最优值。迭代预算80步、相对求解容差1e-5只是数值执行配置，不是结构维数或研究通行门槛。

## 数值一致性

1. 完整域JVP与中心有限差分在多个步长下比较，保留误差曲线，不挑一个好看步长冒充整体精度。
2. 直接核对JVP/VJP伴随内积关系，两侧分别计算，报告绝对误差与相对误差。
3. 保留目标约束残差、驻点残差和求解器返回状态。全局KKT停止不自动等于目标响应约束已准确满足。
4. 比较g_T^T v和-||g_T||；这是一阶目标偏好检查，不以预测响应幅度替代有符号CE变化。

## 条件实现与有限变化

记录条件方向和参考u_T的保护响应能量、完整参数运动范数，以及同一目标约束的响应误差。不能只报告保护泄漏减少而隐去目标响应损失。

在与发现probe不重叠的已有训练侧probe上，报告多个有限写回尺度的CE、Top-1和KL。该probe此前使用过，不能称全新盲测或专家训练外泛化。仅条件优化器产生的v用于这些候选模型，参考u_T不先执行普通训练。

数值结果必须标明是否收敛及实际误差。预算耗尽不是完整空间几何不可行，若需要改进预条件或求解精度，应保留旧记录并另记数值版本。

## 后续边界

条件最优运动不等于低维功能组。完整运动的在线结构学习、独立窗口承载验证、结构约束实际更新及EC性能验证均为后续阶段，本轮不能以事后PCA或旧模式代替。
