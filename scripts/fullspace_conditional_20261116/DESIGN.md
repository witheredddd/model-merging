# 完整空间条件运动：重构后的数学与代码接口

本目录独立于 `0f2d922`。旧代码及旧结果保留为历史，**不再把保持旧 r2 算法语义作为新方法的约束**。

## 1. 已改掉的入口

- 参数变量直接是全部共同视觉参数 `v ∈ R^P`，P来自完整模型参数表，不来自 `len(hD)` 或专家字典列数。
- 不加载或实例化 `Space`，不出现 `Q a`、固定304列、固定张量支持、候选张量截断。
- 不引入 `max_modes`、`max_compensators`、`driver_limit`、`capacity_target`、`novelty_tol`。
- 不沿用旧局部半径或两图EC调度。不使用陈旧Jacobian列决定搜索方向，每次算子作用均在明确的当前完整参数点计算。

旧预测器和全参数JVP/VJP底层可复用：它们的输入本来就是完整视觉参数。这种复用不携带旧专家字典、支持搜索、模式出生或局部EC约束。

## 2. 完整空间条件问题

最新研究对象是带锚点与任务条件的功能需求族，不将CE归一化梯度当作唯一目标。`demands.py`提供CE单位下降需求、完整运动的当前点JVP需求、当前预测点至专家的逐样本Log需求；它们调用同一完整空间条件求解器。一般参数度量M由调用方显式提供，不默认为某个张量权重配方。

此前用户明确选定的CE单位需求、单保护权重1、M=I运行保留为数值基线，而不是新方法的完整定义。参考方向不先执行训练更新；g_T精确为0则记录方向未定义，不生成随机替代。正则参数只表达权衡，不作为模式门槛。定义：

\[
M_Pv=\sum_{p}w_pJ_p^\top J_pv+\lambda Mv.
\]

精确响应问题是：

\[
\min_{v\in\mathbb R^P}\tfrac12v^\top M_Pv,
\qquad J_Tv=y.
\]

新 `ConditionalMotion.solve_exact_response` 通过完整空间KKT矩阵自由MINRES求解：

\[
\begin{bmatrix}M_P&J_T^\top\\J_T&0\end{bmatrix}
\begin{bmatrix}v\\\nu\end{bmatrix}
=\begin{bmatrix}0\\y\end{bmatrix}.
\]

变量始终具有P个参数分量，Krylov迭代只是数值求解过程，不是先验字典或学得维数。输出响应、驻点残差和求解器状态分别记录；迭代耗尽不等于几何不可行，也不自动证明y不可达。

目标不可精确匹配时，论文给出的加权响应拟合是一个不同且必须显式选择的问题：

\[
(M_P+J_T^\top W_TJ_T)v=J_T^\top W_Ty.
\]

`solve_response_least_squares` 用矩阵自由CG实现该问题，不在精确求解失败后偷偷切换，不自动添加输出正则或谱截断。

## 3. 完整功能算子

`FullFunctionalGeometry` 直接提供 `jvp(task,v)`、`vjp(task,y)`、`fisher(task,v)`、完整CE梯度，以及显式CE步长诱导的候选目标响应 `J_T(-step*g_T)`。后者只是可选目标构造，不能替调用者决定step或目标。

所有任务采用相同完整视觉参数顺序与模型位置，平方根概率嵌入逐样本平均。`parameter_point_after(v,scale)` 直接构造完整视觉模型，不能通过旧304维坐标写回。

`fullspace_runtime.load_full_geometry` 直接载入已保存的完整模型点和固定probe，用旧底层 `Context` 加载完整模型；不调用旧 `legacy_adapter`、`Space` 或原控制器。适配模块使用独立名称，避免与底层模型构造器的 `runtime` 模块冲突。

## 4. 数值配置与方法配置分开

必须显式提供：需求来源/尺度/锚点、M、保护权重、λ、求解器数值容差及迭代预算。专家Log只保证处于预测流形的切空间，不保证处于参数Jacobian的像。精确约束与加权拟合显式选择，跨锚点需求不直接混用。数值容差决定方程求解精度，不决定支持、组数或最终维数；不存在旧90%容量或新颖性筛选。

当前全参数迭代使用CPU向量存储及GPU JVP/VJP，避免显式存储P×P矩阵。完整迭代向量仍需要实际内存与传输成本，不能称计算免费。没有写死算法搜索维数上限；调用方给出的max_iterations只是一轮线性求解预算，耗尽如实报告。

## 5. 尚未完成的模块，不冒充已实现

本轮完成的是**完整空间几何与条件求解核心接口**，不是声称整个新方法已经完成：

| 环节 | 当前状态 |
| --- | --- |
| 完整参数域JVP/VJP、CE梯度和写回接口 | 已实现 |
| 带锚点的多来源功能需求族 | 已实现接口；尚未运行真实需求族结构实验 |
| 完整空间等式条件KKT / 加权响应拟合求解 | 已实现，并做数值参考解检查 |
| 给定CE诱导y、欧氏M与谱尺度λ族的A100运行入口 | 已实现双向求解、残差和独立probe有限变化记录；实际运行状态以结果文件为准 |
| 从完整最优运动发现联合结构 | 尚未实现，不把按张量统计当成结构学习 |
| 选择性谱驱动的模式学习和有效维数决定 | 尚未实现；阶段A已有谱只属于旧模式空间 |
| 完整联合结构的在线更新及新EC参数化 | 尚未实现，旧两图代码不作为替代 |

后续应从完整条件最优解及目标需求构造结构，而不是先找几个张量再解补偿。最终怎样从目标族中选择有效模式、怎样定义全局可达的EC控制与终止协议，仍需数学规则；不能删掉304D后又暗中换成另一个固定候选库。

最新数学核对与纠正详见`REVISION_REVIEW.md`。其中明确：最小支持加delta是一种尚需定义的新稀疏解释问题，不直接实现为新的结构门控。

`test_conditional.py` 将矩阵自由完整坐标解与直接约束最优解、加权拟合直接解对照。合成维数只是软件正确性检查，不是研究实验维数。没有把这些测试当成真实模型方法有效性，也没有运行新的EC。
