# DTD 自身功能流：V1 先导实验

本目录实现任务自身的矩阵自由 Fisher 发现与实际参数运动，独立于原来的多任务保护实验。仅加载 DTD。原始正常训练的 17 个参数位置保持不变；先在 step 0 和 step 50 上生成新路径。不以 CE、Top-1 或其他任务的保护代价作为接受条件。

## 实验与证据边界

1. 在每个锚点用 `Fv=J_D^T J_D v` 和块迭代生成敏感候选，记录实际 Rayleigh 残差。`M=I`，不显式形成 Fisher 或伪逆。
2. 初始候选块为 4，这只是起始计算预算，不是内在维数或空间容量上限。单独的 Fisher 提案需在学习数据和两组独立批次中具有机器误差以上的功能创新，才会扩展空间。每个候选保留原始证据；近似置信判断采用图像残差能量的均值及标准误，不能当成严格统计保证。
3. 数值迭代替换已有方向，不以数值残差扩维。沿路径在新位置计算最小范数水平投影，并继续跟踪敏感子空间。水平投影报告输出残差，不在未知最小奇异值时声称参数误差界。
4. 每个锚点采集正负方向、混合方向与冻结基对照，每条短路径先采样 4 步。先用前两个控制轴检验局部二维运动，这不是对整个敏感分布的验证。每个在线/冻结配对使用相同初始物理基与步数；步长分别按功能半径校准，不能声称参数步长完全相同。
5. 在平方根概率的**逐图像球面乘积**上计算 Log，与同位置 JVP 比较，并检查半步。初始功能半径 0.01、局部相对误差预算 5%，均为先导配置，不是成功结论。CE 和准确率仅作为观察量。
6. 使用两种闭环顺序与 1、1/2、1/4 尺度。各闭环共享初始基，四段使用同一参数步长；必要时缩步并整圈重启。闭环期间记录新功能方向证据但保持试验秩，出现新增方向证据时须质疑恒秩假设。报告闭合残差及其面积归一化值，有限闭环不构成 Frobenius 可积性证明。
7. 在新位置保留水平投影的垂直剩余重构配方，循环抽查其有限扰动对功能及后续方向响应的影响。此反事实观测不改变接受路径，不作为新敏感方向。

原独立 probe 池被分为出生验证 A、B 和留出评估 C。C 不参与出生与步长接受；完整池已部分用于出生，不能再称整个池为留出集。随机参数方向与旧 WLS 坐标均在同一锚点重新测量 DTD 响应；旧 WLS 只作基线，不生成本轮主要方向。各方法的学习开销不同，需要连同累计算子成本解释，不能将其称为严格等计算预算比较。

## 运行

依赖本仓库相邻的 `fullspace_conditional_20261116`、`eight_task_coupling_20261116`、`functional_control_r3_20261117`、`functional_space_20261117`。模型、探针、数据及原始轨迹由外部路径提供。

```bash
python worker.py --output /path/to/new_DTD_output \
  --trace /path/to/DTD/trace --coordinates /path/to/config.json \
  --inventory /path/to/INVENTORY.json --probes /path/to/probes.json \
  --anchors 0 50 --candidate-block 4 --path-steps 4 \
  --numerical-rtol 0.001 --functional-radius 0.01 --local-error 0.05 \
  --wls-source /path/to/old_WLS_output
python -m unittest test_flow -v
```

`numerical-rtol` 控制数值迭代，不控制准确率。CG 和特征迭代可恢复，不将检查点间隔当成迭代上限。每个输出目录独占文件锁；恢复时核验源码与冻结输入哈希。`migrate_checkpoint.py` 仅允许在尚无实际运动的 DISCOVER 状态下进行显式、留痕的源码迁移。

## 保存与判读

`CURRENT.json` 指向原子提交的状态，`status.json` 为简要进度，`NUMERICAL_HISTORY.jsonl` 保存特征残差。`validation/`、`baselines/`、`innovations/` 保存独立响应与候选证据。

`flows/` 每个完成的转移记录实际前后参数、参数位移、前后物理基、控制、步长试验、学习与留出功能响应、水平投影、子空间变化及累计算子开销。新参数状态与方向以内容哈希命名，均可重构；数值临时向量只有在当前状态及所有流记录均不再引用时才清理。中断时的 `pending_transition` 保留已接受的新位置，并从该位置恢复水平求解。

先导完成标记为 `PILOT_COMPLETE`，只表示采样计划完成。需要根据独立功能贡献、缩步规律、冻结基比较和闭环结果分别评价敏感空间、连续控制分布与流形假设。尚未实现 JEPA 训练；按方案应先用真实路径验证几何演化的可预测性，再决定是否进入该阶段。不能用源代码测试通过或四个初始方向宣称发现低维流形。
