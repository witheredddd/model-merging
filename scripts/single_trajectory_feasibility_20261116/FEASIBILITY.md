# 用现有这一条轨迹判断可行性

**不用增加seed，也不用采集24条轨迹。现有数据支持低维控制与功能几何连接的实现可行性，但还不能证明“仅靠历史轨迹做FPCA，就能学出下一步可用的控制方向”。**

本轮只分析现有五次接受更新。没有新训练、新轨迹、JVP或参数写回，只补了初始参考模型在p0/p4上各两个任务的4次前向，耗时约45秒。三项数值测试通过。

## 已经能够确认的部分

对每个样本分别使用平方根概率球面的Log映射，将六个模型位置表示在固定初始概率点的参考切空间。没有把整批样本拼接后当成一颗球。随后计算DLog·J·B·z与真实Log坐标增量之间的误差。

| 指标 | 结果 |
|---|---:|
| 共同概率参考坐标下的联合预测误差 | 0.34%–0.64% |
| 联合方向余弦 | 至少0.999983 |
| 弧长加权功能速度前两轴能量，p0 | 99.463% |
| 弧长加权功能速度前两轴能量，p4 | 99.469% |
| 弧长加权参数速度前两轴能量 | 94.751% |

这些结果支持：已有参数控制模式能够提升到真实参数更新，并解释对应功能变化；把不同位置的功能变化放到共同概率参考坐标在数值上可行。它们不等于一个已经学成、能够外推的FPCA控制器。

时间统计按真实参数弧长加权。这里的时间方向协方差是单路径的描述性统计，不冒充跨轨迹函数协方差。p4为此前已使用的探索性稳定性数据，未打开p6或Test。

## 最关键的可行性障碍

第三次更新（日志step2）之前，仅用已执行的功能运动张成空间表达下一步Log功能增量，残差为：p0 99.918%，p4 99.741%。因此，全轨迹前两轴能量很高，不能当作前两步就已学会未来方向的证据。

而在第三次更新的当前参数位置，已有三个旧控制模式的响应空间留下的残差只有6.111%。这说明控制字典中包含尚未在实际运动中充分执行的功能自由度。仅压缩已执行轨迹，会漏掉这些信息；当前任务梯度、模式响应和条件补偿需要继续参与运动选择。

这项前缀检查只是“已有方向能否表达后续运动”的检验，不是未来幅度预测，也不是所有动态函数模型都不可能外推的证明。

## 能表示，不一定能在预算内实现

用旧三个模式在原平方根概率坐标里最小二乘逼近第三次实际响应，残差约6.12%，但该投影所需参数范数为预算的1.140倍。该具体投影超预算，不能直接写回。

这不是旧三维空间完全不可用的证明；在约束下重新优化可以得到别的可行运动。它表明轨迹压缩之后，仍需保留参数位移、保护任务响应和CE方向约束。不能把低重建误差直接当作控制可行性。

## 当前数据能否直接拟合文中的FPCA？

按附件的跨轨迹中心化定义，当前只有一条函数曲线时，均值就是这条曲线，协方差核恒为零：

\[
N=1\quad\Rightarrow\quad V_1(s)-\bar V(s)=0,\qquad C(s,s')=0.
\]

不中心化时，可以把这条曲线本身当作一个函数分量并得到100%重建，但这不证明可复用结构。把时间片或不同模式当作独立轨迹，会改变统计对象，不能无说明地替换样本定义。

问题不在于必须增加随机seed。同一次运行也可以研究不同任务曲线；本轮按用户要求不扩大采集，只给出当前单条轨迹能够支持的判断。

## 当前轨迹的任务条件不能省略

五次实际更新的目标/预算依次为：Cars/1.0、DTD/1.0、Cars/0.1、DTD/0.3、Cars/0.1。它不是固定偏好的单一动力学。第三次新方向也伴随目标和预算切换，不能把前缀难以表达该方向简单归因为算法失败。

如果沿这次运行学习动态结构，任务方向与保护预算应成为条件信息，当前模式及其参数提升也应保留。否则，学到的主要可能是任务切换形成的两类运动，而非可用于后续控制的共同几何规律。

## 判断

**表示、概率坐标和条件控制链路具备单次原型可行性；历史轨迹到可用未来控制方向的学习环节尚未成立。** 现有五个增量足够定位这个瓶颈，不足以认证通用FPCA特征函数、稳定曲率、内在维数或EC搜索空间。

当前不需要多seed、LTSA、曲率模型或大批方法对照。先保留同一次运行中的任务条件与当前几何，用前段信息决定后段运动，再依据真实约束和功能收益判断是否可用。这是下一次实际学习验证的范围，本轮没有自动启动续跑。分析仍限制在304维专家重组空间，不能外推为完整86M参数空间的内在几何。

已有历史反馈尚未改变出生选择的结论也仍然成立；本次参考坐标修正并未改变这个事实。
