# Functional Geometry EC v2.0 — 从任务数据在线学习几何（不依赖专家 checkpoint）

## 必须修正的研究设定

**输入：**CLIP ViT-B/16 预训练视觉编码器 `theta0`、八个下游任务的训练/验证数据、各任务对应的分类 head 或零样本文本分类器。**不要求任何已完成微调的专家 ckpt、`tau_k`、训练轨迹。**任何现存专家只可作可选、不可阻塞的对照。初始的 `tau_k` 尚不存在；最终 `tau_k := theta_k - theta0` 是在线低维学习得到的专家更新结果。

**共同结构不是预置假设：**不预先划分层/Attention/MLP 参数块；不预设三个四维流形或二元共享/隔离；不以预设低秩三因子分解作为创新。所有参数方向是同一组展平视觉 backbone 参数的完整 D 维向量，可跨多个矩阵。计算资源要求显式设置候选总秩上限 `r_max`，但这不是预先指定功能块数。

## 核心对象

1. 第 k 个任务的低维专家：`theta_k = theta0 + B z_k`，B∈R^{D×r}，B^T B≈I，z_k∈R^r；不同任务的 z_k 独立，B 由八任务训练梯度共同、**在线**形成。初期统一共享候选空间并不意味着任务最终必须使用相同方向：某些方向只被某些任务使用；候选池可按任务残差梯度逐渐扩展。`theta0` 不更新，任务特异 head 不融合。
2. 在共同参考点 θ_ref 上的预测功能度量：`F_k(θ_ref)=E[J_logit,k^T (diag(p_k)-p_k p_k^T) J_logit,k]`；小矩阵 `G_k=B^T F_k B`。这是局部输出 KL 的二阶项，不能仅凭 G 判断损失改善的正负。
3. 有符号的 CE 方向响应：`h_k = B^T grad_theta L_k(θ_ref)`。
4. 学习到专家后定义：`tau_k=B z_k`，不从预先存在的 ckpt 读取；找到功能共同块 `B_m` 后 `tau_{k,m}=B_m B_m^T tau_k`（只在完整正交分解且涵盖全部学习方向时精确）。

## 阶段 A：无专家的冷启动（必须首先跑通）

1. 自动找到 `theta0`、八任务 loader 及各任务 head。若没有有效 head，优先按工程既有零样本 CLIP 分类规则；确实不存在时只训练对应任务的轻量线性 probe，视觉 backbone 保持 θ0 不变。**不得将 probe 当成完成的视觉专家。**
2. 在冻结的 θ0 视觉 backbone 上，对每个任务从训练集取 4 个不同 mini-batch，计算对同一套视觉参数的完整任务梯度 `g_{k,b}=∇_theta L_k(theta0; batch)`；八任务合计最多 32 条 D 维方向。计算的是梯度，**不是专家 delta**，不改变 backbone 权重。对梯度按各自范数归一化，保留原始范数记录用于可比性。
3. 将所有梯度按固定全模型参数键展平，构造梯度 Gram `K_ab=<g_a,g_b>`，做稳定 eig/QR 正交化。**不要把 32 条原始梯度全部塞进初始 B**，否则 `r_max=32` 将无法在线扩展。先计算每任务 4 条梯度的均值方向 `gbar_k`，正交化后优先保留这些最多 8 个任务方向，再从各任务的残余梯度中按均衡的能量贡献增加至 `r_init=12`（若有效秩不足则按实际秩）。得到 `B0∈R^{D×r_init}`。零梯度必须报告；与任意网络模块的人工分组无关。
4. 从 theta0 上直接得到初始 `G_k(B0;theta0)`，可先用每任务 mini-batch 梯度协方差 `B0^T C_k B0` 作廉价代理（须明示它不是预测 Fisher），在实现 JVP 后以预测 Fisher 矩阵为准。各任务尺度单独校准，不把 8 个 head 的 logits 混合计算。
5. 此时可以完成无专家的第一项真实检查：跨任务 `G_k` 是否有稳定非平凡的共同结构。**只能得出初始梯度候选空间的结论**；不许据此推断训练完成的几何也一样。

## 阶段 B：真正的低维方向学习与八个专家训练

1. 使用在线梯度子空间跟踪而非固定 B0。保持 `B` 为候选方向池；当前各任务独立保存 `z_k`，任务 k 的 forward 使用 `theta_k=theta0+B z_k`。每个任务独立做交叉熵训练并交替抽取 task batch；八个任务可以共用几何采样与基底，但各自的专家模型不同。目标 `Σ_k L_k(theta0+B z_k)` 仅在本任务专家上计算对应损失；采样需按任务平衡。**这是几何协同学习下的专家训练，不是要求单个模型同时解决八任务。**
2. 初始化全部 `z_k=0`，第一步仅用 `B^T g_k` 更新对应的 z_k；不要声称 `z=0` 时通过 CE 可以更新 B，因为 `∂L/∂B=g_k z_k^T=0`。本 v2 优先使用显式在线梯度跟踪来调整 B，而不优化巨大的 D×r Adam 基底。
3. 每经过一个短训练窗口，分别在当前 `theta_k` 计算新任务梯度 `g_k`，得到 `r_k=(I-B B^T)g_k`。若投影内梯度不足、验证 CE 改善停滞、且剩余梯度方向具有显著一阶下降潜力，则把归一化残差方向加入 B；新列对所有 z_k 初始为 0。此种**追加新正交列**保持已学到各专家的当前模型**完全不变**。不需要先有八个专家更新。
4. 新方向先测本任务的真实一步 CE 下降与组外任务在共同参考 θ_ref 的输出敏感性，借鉴 LoDA/OSRM 的组内能量、组外低响应思想；不能只用比值大宣称隔离，需同时约束绝对组外响应。可保留重要的部分共享/冲突方向，不强制只接受隔离方向。
5. 候选基底从 `r_init≤12` 起步，最多到 `r_max`（默认首次试运行 32；资源允许可在不覆盖旧检查点条件下扩为 48 或更高），不预设块数。如果超限而任务（特别 DTD）明显达不到全量参考训练能力，明确记录**当前低维参数化容量不足**，而不是放松验证标准或伪造性能。
6. 允许可选精细的 Grassmann 更新，但必须单独验证基底更新不会改变当前已有模型：纯正交换基 `B'=BQ` 时必须同步 `z'_k=Q^Tz_k`，参数完全不变；真正改变 span(B) 时不可用该恒等式，必须精确存储旧方向、扩展基底，或者报告/验证重投影误差。严禁以“中心保持”掩盖模型位置改变。
7. 优先仅训练 48 个现有视觉 attention/MLP 权重矩阵中的等价参数集合，保持任务 head 与现有 pipeline 一致。所有数值/模型保存新目录。低维任务准确率应与可获取的完整微调参照对比：DTD 的目标 val ≥80%，未达到时报告不合格，不能据此宣称结构有效。

## 阶段 C：在线功能矩阵和共同块检测

1. 在初始化 θ0、一个联合训练过程中的公共中间参考模型以及训练后的基线融合参考模型，分别计算 8 个小矩阵 `G_k=B^T F_k B`。**同一轮比较必须同一 θ_ref**，不能拿不同 θ_k 处的 G_k 假装能直接比较任务共享关系。
2. 使用现有 `functional_commutant_core.py` 对 `G_k` 作对称无迹交换子谱分析：`X G_k - G_k X≈0`。只有稳定非标量解、显著特征间隔、跨块残差在独立训练子集上仍较小，才记录可解释的近似共同块。若无结构，报告 `no stable common block detected`，不强制 2 或 3 块。
3. 对每个块 `B_m` 计算 `(a) G_{k,m}=B_m^T F_k B_m` 的 λmax（跨任务敏感/隔离）、`(b) h_{k,m}=B_m^T ∇L_k` 的方向（改进/冲突）。Fisher / Gauss-Newton 不含改进正负信息。仅当参考位置和变异尺度内组外损失影响经验证较小时，可将隔离贡献视为近似固定。
4. 部分共享任务子集由测得的功能强度和交互关系推断；不枚举 255 个子集作为预置任务划分。共同块内不要求每个 rank-1 方向都功能独立。

## 阶段 D：融合的准备和可选 pilot

训练完成后才存在 `tau_k := theta_k - theta0 = B z_k`。若共同块检验通过，令 `tau_{k,m}=B_m B_m^T tau_k`，用 `theta_merge = theta0 + Σ_{k,m} λ_{k,m} tau_{k,m}` 进行结构化系数搜索；保证设为某任务所有 λ=1、其他 λ=0 时能严格回到其训练出的专家。若共同块不成立，退回 `theta0+Σ_k λ_k tau_k` 的全局模型融合基线；**仅训练专家是不等于已经完成 EC 验证**。固定的隔离分量是否能无害叠加，必须在实际融合模型上检查；不得直接据局部 Fisher 零值宣称全局无干扰。

## 运行原则 / 防止重复错误

- 不允许 `expert checkpoint missing` 导致算法停止；专家 ckpt **不是输入**。
- 不允许生成 `tau_k = expert - base` 的冷启动逻辑；在专家训练完成之前没有 tau_k。
- 不允许用已有 v1 的“专家更新/专家 checkpoint 作为必要输入”的入口。
- 如因工程不支持高维基底或 8-task gradient 而无法运行，先输出真实接口阻塞并实现最小的梯度探针 / 32×32 功能矩阵阶段，不伪造结果。
- 先通过 `8×4` 梯度冷启动+ `G_k(theta0)` 的最小实验，再继续在线训练。每阶段自动缓存、独立验证、记录时间显存，优先使用 A100 80G。原始 ckpt / 旧结果永不覆盖。
- 仅采用训练集作为几何学习及校准数据，独立训练子集验证结构稳定性；validation 作停止/选择，test 最终一次评估。

## 一句话描述

**预训练 θ0 与八任务数据 → 初始多任务梯度方向 → 在线任务驱动 Grassmann/梯度子空间学习 → 八个低维专用专家及功能小矩阵 → 自适应共同块识别 → EC 融合。**

版本差异：v1 是“已有专家 → 事后分解”；v2 是“没有专家 → 在线学习方向并形成专家”。二者不能交替混用。v1 交接包已作废。
