# v3：先充分学习任务更新

版本`tfpml-0.3.0-expression`；当前实现只执行阶段A。
阶段B扰动与阶段C冻结不在这轮训练中，不将单点任务准确率当作流形成立。

映射是逐权重独立傅里叶展开：

`h_i(z) = sum_k [a_ik sin(omega_k z + b_k) + c_ik cos(omega_k z + b_k)]`

`delta_theta(rho,z) = rho h(z) / ||h(z)||`。

所有输出共享同一个3维坐标和16组可学习频率；每个权重有自己独立的32个系数。
每个原矩阵单独分配系数，纯属计算与内存组织，不共享128→4096输出层。
有限傅里叶模式仍意味着整个映射由32个高维系数向量组合而成；这是显式函数表示，
不是四维流形的理论结论，也不是各4096输出块共享129维字典的旧限制。
频率个数可显式改变，当前16组按80GB显存选定，不宣称最佳。

84,934,656个权重对应2,717,908,992个系数，另有64个频率/相位参数。
训练映射参数共2,717,909,056，控制坐标仍是rho加3维z。
系数FP32参数、梯度和Adam两份状态约40.5GiB，不能以4个控制变量声称训练省参数。

训练设置：20轮，每一步都更新系数、频率、相位、rho、z。
系数Adam学习率1e-5，频率/相位1e-3，rho .05，z .005；
首轮线性预热，随后余弦降到5%，不增加结构罚项。
与此前相同CLIP、48个矩阵、数据split及重建冻结头。
验证CE选择最佳checkpoint；锁定选择后一次测试，不利用测试集调参。
主要验证目标81.7%，测试80%为原任务性能门槛；达到门槛只说明任务表达阶段成功。

阶段A结束前不自动冻结；即使达到目标，也不自动进入扰动阶段。
保存best、完整epoch边界resume，以及第1/5/10/15/20轮映射快照，
每个快照包含当时的psi、rho、z，避免只存旧坐标却失去历史模型对应。
未来历史状态研究必须以这些真实快照为依据。

资源：显卡实测峰值48.94GiB、普通步0.8—1.0秒；
一个映射权重快照约10.1GiB，完整resume约30.4GiB；
若干快照、best、resume及原子保存临时文件预留150GiB磁盘。

验证：小模型能够精确输出132×132单位块矩阵（秩132），
说明旧的129输出字典上限已移除；单位方向归一化与坐标有限差分通过。
完整CLIP两步检查：每个独立系数参数的Adam step都实际增加。

运行：`bash scripts/tfpml/launch_expression.sh`。
输出：`results/TFPML_v3_expression_k16_d3`。
v1和v2记录保持原样。
