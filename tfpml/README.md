# 新方案：任务驱动傅里叶参数曲面（仅 DTD 主方法）

旧自适应 Grassmann 方案停用。按用户要求不安排对照或额外消融。

模型：原 CLIP ViT-B/16；48个视觉矩阵共84,934,656维；同一DTD类别头。
训练数据3384、验证376，原seed=0划分；最终验证选择锁定后才测试1880张。
分类头是前次按原函数重建的冻结零样本头，尚未与旧源头逐张量核对。

生成：每个原矩阵独立切4096参数计算块，16维固定结构编码加可学习嵌入。
共享同一个3维角向坐标；64组有界可学习频率产生sin/cos特征。
共享两层128宽网络输出每块4096值，去掉尾部padding，全局归一化。
最终theta=theta0+rho*h(z)/||h(z)||；控制变量共4个。
通过functional_call直接反向至映射和坐标，不覆盖模型参数.data。

训练20轮：至少前5轮CE训练映射和坐标；验证达到70%才进入几何阶段。
几何阶段每50步采近期坐标锚点，当前任务梯度产生阻尼Gram低维更新，
独立、不重叠训练图像评价更新后CE并训练映射；采用delta_q停止梯度的一阶近似。
历史坐标在当前映射下重解释，不能视为精确重放旧模型。
如果门槛始终未达到，则报告几何反馈未验证，不将普通CE训练包装成成功。
最后3轮冻结生成器仅学习坐标，从该冻结阶段按验证CE选择模型。

最终报告：冻结后Val/Test CE与Acc；参数Gram谱、输出坐标Jacobian谱，
各坐标正负扰动的参数距离、CE、KL；训练参数量、显存、步时。
Test>=80%只是性能门槛，不足以独立证明多方向有用或非线性优于线性。
本轮不做对照，所以不能宣称非线性优势或局部反馈的因果收益。

两步实际检查：任务梯度链路已通过，普通步约0.8—1.1秒，峰值约9.32GiB。
几何更新和最终诊断更昂贵，耗时由实际日志报告，不承诺用餐结束前跑完20轮。
